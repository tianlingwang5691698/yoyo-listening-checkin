# 小程序视觉重设计提案

## 目标

把当前界面从“功能入口集合”升级为“高级、温和、有活力的亲子英语学习产品”。

关键词：

- 高级亲子教育
- 温和科技感
- 低饱和灵动
- 少卡片堆叠
- 轻量数据表达

## 视觉方向

### 配色

推荐主方案：

```text
背景：#F1EFE8
主文字：#20242B
次文字：#6D7178
主色：#B87963
辅助绿：#6E9488
辅助蓝：#657F9F
辅助金：#B9A064
辅助紫：#82799F
卡片白：#FFFDF8
```

使用规则：

- 背景不要纯白。
- 主色只用于主动作、当前状态、重要入口。
- 模块色只做小面积识别，不做大面积彩色块。
- 渐变只用于主卡，不用于所有入口。

### 字体

继续沿用项目 6 层：

```text
type-brand
type-page-title
type-card-title
type-section-title
type-body
type-caption
```

规则：

- 不用 `font-weight: 900`。
- 标题不追求大，追求留白和稳定。
- 首页模块标题控制在 `type-section-title` 或更小。

### 图标

不建议继续使用：

```text
emoji
单字圆标
过粗 CSS 手绘图标
```

推荐：

```text
统一线性图标
2rpx 线宽
圆角端点
每个图标只用一个模块色
```

实现方式：

- 若项目能接入图标库，优先用 `lucide` 风格图标。
- 若小程序不方便接入，使用 SVG asset，而不是复杂 CSS 手绘。

## 页面改造原则

### 首页

目标：进入学习，不做看板。

结构：

```text
品牌标题
今日听力主卡
学习入口区
```

入口建议：

- 不用六个强卡片抢焦点。
- 可以使用“轻列表 + 小图标 + 一行说明”。
- 入口区整体是一个安静容器，内部行项目轻分隔。

### 写作页

目标：像作文工作台，不像表单。

结构：

```text
题目主卡
编辑区
批改结果
```

规则：

- 题目卡可用轻渐变。
- 编辑区必须白、干净、可写。
- 提交按钮只保留一个强动作。

### 家长页

目标：先给结论，再看细节。

结构：

```text
孩子日报主卡
今日结论
最近 7 天
```

规则：

- 不把“今日学习量”放首屏第一位。
- 数字弱化，文字结论优先。
- 评分、完成数、分钟数放详情或二级卡。

## 组件规则

### 主卡

```text
圆角：18-22rpx
背景：近白或轻渐变
边框：1rpx 半透明白/灰
阴影：轻，不能像浮层广告
```

### 普通入口

```text
圆角：14-18rpx
背景：近白
左侧图标：小尺寸
右侧箭头：可选
说明：最多 1 行
```

### 按钮

```text
一屏最多一个主按钮
主按钮使用主色
次操作用文字或浅色胶囊
```

## 执行顺序

1. 先冻结视觉 token
   文件：`styles/themes/warm.wxss`

2. 再改首页入口
   文件：`pages/home/index.wxml`、`pages/home/index.wxss`

3. 再统一写作和家长页
   文件：`pages/writing/detail/index.wxss`、`pages/parent/index.wxss`

## 验收标准

- 首页首屏不再像功能宫格。
- 同一屏不超过 2 种卡片权重。
- 没有 emoji 图标。
- 没有明显糖果色。
- 没有黑白丧葬感。
- 渐变只出现在主卡。
- 家长页先读到一句结论，而不是一堆数字。
