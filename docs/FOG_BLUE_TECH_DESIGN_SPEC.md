# 雾蓝科技感设计规范

本规范定义当前小程序的新视觉方向。后续首页、听力、阅读、写作、口语、词汇、音频入口及其详情页，均以本文为准。

## 设计定位

- 高级亲子教育，不做儿童化、后台化、报表化。
- 温和科技感，不做实验室、科幻、霓虹、深色控制台。
- Apple 式留白，界面少解释、少按钮、强层级。
- 视觉关键词：雾蓝、晨光、玻璃、声波、珍珠白、低饱和珊瑚。

## 主题入口与换肤规则

- 当前主题显示名为“雾蓝玻璃”；代码内暂沿用 `warm` key 兼容旧缓存。
- 新增完全不同主题时，先在 `utils/theme.js` 增加主题 key、label、导航色，再新增对应 `styles/themes/*.wxss`。
- 所有页面根节点必须保留 `theme-{{theme}}` / `themeClass` 能力，底部导航必须同步使用同一 theme class。
- 新主题优先覆盖 CSS 变量和主题类，不直接改业务 WXML，不改数据字段，不为主题复制页面。
- 如果新主题需要完全不同图案，可新增主题专属图案类或素材，但入口、任务、记录等业务结构保持一致。
- 先做 4 个验收面：首页、底部导航、词汇书库、一个详情页；通过后再扩到所有模块。

## 色彩

- 页面底色：`#F6FBFD`、`#EDF6FA`、`#EAF3F8`。
- 主文字：`#17314F`。
- 次级文字：`#607087`、`#728196`。
- 主操作：珊瑚渐变 `#F2A18E -> #DF7F68`。
- 进度与完成：鼠尾草绿 `#86AAA1`。
- 音频/科技辅助：雾蓝 `#8DB7D4`、`#BFD7E8`。
- 禁止：大面积米黄、棕色、亮蓝、亮紫、纯黑白、红色压力感。

## 材质

- 主卡：半透明雾蓝玻璃，白色高光边，柔和蓝灰阴影。
- 普通入口：珍珠白玻璃卡，轻阴影，圆角偏大但不能幼稚。
- 阅读/写作正文：纸感白底，边缘轻玻璃，不要深色卡。
- 按钮：只允许一个珊瑚主按钮，其余用浅雾蓝胶囊。

## 字体层级

- 页面主标题：42-52rpx，深雾蓝，字重 500-600。
- 主卡标题：60-72rpx，仅用于今日听力或核心任务。
- 卡片标题：32-36rpx。
- 辅助文字：22-28rpx。
- 禁止负字距、粗暴 `900`、英文大写 eyebrow。

## 导航

- 顶部导航背景必须接近页面底色：`#F6FBFD`。
- 底部 tab 使用雾蓝玻璃胶囊，不用米色、不用系统灰底。
- 图标使用同一套细线 CSS 或矢量风格；禁止 emoji、杂乱符号。
- 选中态：深雾蓝文字 + 小珊瑚点。

## 首页标准

- 顶部标题按时间问候：`上午好，昵称` / `下午好，昵称` / `晚上好，昵称`。
- 今日听力是首屏主角：大玻璃卡 + 声波 + 悬浮字幕 + 目标进度。
- 六入口只保留图标和标题，不放说明文字、不放小进度条。
- 底部统计只放真实数据：连续学习、累计学习时长。

## 入口页标准

- 不做普通列表堆叠。
- 可用“玻璃分组 / 抽屉 / 音频波段 / 纸面层级”替代列表感。
- 每页首屏只出现一个主要任务。
- 行项目可整行点击，不重复放同权重按钮。

## 内容呈现模式

入口后的页面不能只是把数据排成列表。每个模块必须根据学习动作设计自己的内容形态：

- 音频内容：使用横向频道、阶段胶囊、声波轨道、节目抽屉。
- 听力课程：使用大播放器、声波进度、三遍节奏、悬浮 transcript。
- 阅读目录：使用试卷分组面板、阅读书页、地区/年份抽屉。
- 阅读详情：原文为主，题目像边注或轻问题卡，不抢原文。
- 语法：考点树、诊断题卡、选项矩阵，不做题目流水列表。
- 写作：题目纸、写作纸、批改报告三层结构。
- 口语：声音任务舱、录音圆钮、声波反馈、三项能力仪表。
- 词汇：书库、词卡、复习栈，不做词条清单。

若数据量确实很多，可以保留可滚动内容，但视觉上必须是“分组内容容器 / 抽屉 / 卡组 / 轨道”，不能像后台列表。

## 模块图案语言

所有模块共享雾蓝、晨光、玻璃、珍珠白，但图案不能全部复用同一种圆弧和竖条。每个板块必须有自己的识别图案：

- 听力：声波、时间轴、播放圆环、字幕气泡。
- 音频入口：音轨、频道波段、阶段轨道、音频胶片。
- 阅读：纸页边缘、段落高亮、书页折角、答案定位线。
- 语法：句法节点、选择矩阵、考点树、校准刻度。
- 写作：纸张纹理、笔迹线、段落分层、批改报告标尺。
- 口语：麦克风声圈、录音波纹、呼吸圆环、三项能力仪表。
- 词汇：词卡堆叠、书脊、记忆栈、轻量标签。

禁止把首页底部报告里的圆弧+竖条图案复制到所有模块。图案只做轻背景或信息辅助，不抢主要内容。

## 听力与音频

- 听力目录：像音频内容库，不像资料表。
- 课程页：播放器是主角，使用声波、圆形主控、单一进度。
- transcript：玻璃浮层或纸面文本，不能像系统日志。
- 不展示普通用户不需要的云路径、ready、temp-url 等调试信息。

## 阅读

- 目录页：一模/二模/真题卷做成玻璃分组。
- 详情页：原文优先，使用大纸面阅读区。
- 题目与解析轻量化，避免一屏多张厚卡。
- 高亮颜色只用雾蓝、鼠尾草绿、低饱和珊瑚。

## 写作

- 页面像写作工作台。
- 题目卡轻，输入区大，像高级纸张。
- 批改结果像温和报告，不用红色制造压力。
- 只保留一个强提交按钮。

## 口语

- 页面像声音练习舱，但不出现实验室元素。
- 中心是录音按钮、波形或声音圆环。
- 分数用三条轻仪表，不做成绩看板。

## 词汇

- 词库像高级书库/卡片库。
- 单张卡片只保留词、音标、释义、例句和两个底部动作。
- 不要学习说明堆叠，不要进度报表堆叠。

## 禁止项

- 不使用“实验室”视觉元素：试管、培养皿、样本台、暗色科技屏。
- 不使用 emoji 图标。
- 不使用米色/棕色作为主导航或主背景。
- 不使用普通后台列表作为主视觉。
- 不使用假数据；首页目标、连续、累计必须来自真实数据。

## 自检

- 页面是否和首页同一雾蓝晨光体系。
- 是否只保留一个主操作。
- 是否去掉无意义说明文案。
- 是否没有列表堆叠感。
- 是否没有调试/后台/控制台文案。
- 是否通过 JS/JSON 基础检查。
