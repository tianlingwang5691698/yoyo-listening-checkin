# 图书馆静谧主题设计规范

## 主题定位

- 主题 key：`library`
- 显示名：`图书馆静谧`
- 角色：第二套可切换主题；`warm / 雾蓝玻璃` 继续作为默认主题。
- 气质：安静、成熟、专注、可信，像一间有温度的私人英语书房。
- 主题切换必须整套生效：页面结构、入口形式、图案、材质、按钮、导航和信息密度都可不同，不能只换颜色。

## 主题架构

- 运行态使用 `themeId + pageSkin`：`themeId=library`，各页面拥有自己的 `pageSkin`。
- 业务数据、路由、云端字段、任务状态和交互结果与雾蓝玻璃完全共用。
- 页面允许为 `library` 提供独立呈现分支，但不得复制业务请求、状态计算或提交逻辑。
- 第二主题所有页面完成并验收后，才在“我的”页恢复主题切换入口。
- 主题设计稿、参考图和说明全部放在 `docs/design/library-theme/`；`docs` 已从小程序上传包排除。

## 全局视觉

### 色彩

- 深胡桃木：`#2B211B`
- 墨水蓝：`#14283A`
- 羊皮纸：`#F3E8D4`
- 柔和米白：`#FAF5EA`
- 黄铜：`#B89562`
- 苔藓绿：`#7F8C78`
- 次级文字：`#6F675F`
- 错误态使用低饱和砖红，禁止大面积鲜红。

### 材质

- 主背景使用真实书房空间、木纹、纸张和局部暖光，不铺满纯棕色。
- 主内容使用清晰纸面或墨蓝面板；玻璃只能小面积用于导航，不沿用雾蓝悬浮字幕卡。
- 边框使用细黄铜线或纸张压痕；圆角控制在 `8px` 以内。
- 阴影短而柔，表达纸张层次和桌面关系，不做厚重悬浮卡。

### 字体与图标

- 中文标题使用克制的宋体感或项目可用的系统衬线回退；正文继续使用系统无衬线保证可读性。
- 数字、时间、音频刻度采用编辑排版感，不使用控制台字体。
- 图标统一为细线雕刻风；每个模块必须有自己的图案语言。
- 禁止 emoji、糖果图标、粗 CSS 图形和所有页面复用同一圆环。

### 导航

- 顶部导航与页面场景融合，文字使用米白或墨蓝，依据背景自动切换。
- 底部导航使用低透明墨蓝书脊条；选中态为黄铜图标、短下划线和清晰文字。
- 底部导航尺寸稳定，不随页面内容或主题切换跳动。

## 首页基准

- 保留现有真实结构：动态问候、日期与 Day、今日听力、六入口、四项底部导航。
- 今日听力使用羊皮纸主面板、书页边注、黄铜时间轴和真实目标进度。
- 六入口固定为：听力、阅读、语法、词汇、写作、口语。
- 不显示学习报告、累计时长、任务总数或入口下的小进度条。
- 首页基准图：`docs/design/library-theme/home-reference.png`。

## 模块页面归属

- 听力：`pages/material/index?module=listening`、`pages/listening-plan/index`、`pages/listening-material/index`、`pages/material/detail/index`。
- 阅读：`pages/reading/index`、`pages/reading/detail/index`。
- 语法：`pages/grammar/index`，覆盖目录、练习、提交、解析等页面状态。
- 词汇：`pages/reading/flashcards/index`，覆盖书库、词卡、复习和完成状态。
- 写作：`pages/material/index?module=writing`、`pages/writing/detail/index`。
- 口语：`pages/speaking/index`，覆盖任务、录音、评分和回看状态。
- 音频：`pages/level/index`、`pages/level-stage/index`、`pages/lesson/index`。
- 成长：`pages/record/index`、`pages/home/completed/index`。
- 我的：`pages/profile/index`、`pages/identity/index`、`pages/family/index`、`pages/parent/index`、`pages/parent/detail/index`、`pages/admin/index`。

## 模块专属图案

- 听力：黄铜时间轴、声音书签、转写边注、唱针刻度。
- 阅读：书页跨栏、段落页码、批注线、答案索引签。
- 语法：句子排版台、主谓宾字模、语法校样符号、结构连线。
- 词汇：书脊词库、索引卡、抽认签、记忆抽屉。
- 写作：稿纸、墨迹、编辑批注、段落尺和校对章。
- 口语：阅读灯下的录音台、黄铜麦克风、呼吸刻度、声音回放槽。
- 音频：唱片目录、磁带/音轨书脊、章节索引、播放器唱针。
- 成长：借阅记录、阅读年轮、日历压印、成长书签，不做仪表盘。
- 我的：藏书票、会员档案、家庭借阅卡、日报信笺和账号印章。

## 每页设计交付要求

- 先读取真实 WXML、JS 和状态字段，再设计；不得凭空增加业务内容。
- 每页至少覆盖：首屏、加载、空状态、正常状态、完成/结果状态、错误状态。
- 同一模块的入口页与详情页必须有层级差异，不能重复一张卡片模板。
- 每页只保留一个强动作；整行可点击时不增加同权重按钮。
- 文案使用项目现有文案，设计稿里的示例数据必须明确是布局占位，不进入代码。
- 每个模块输出一份逐页规范和一张多屏视觉板；视觉板只用于评审，不进入小程序包。

## 验收

- 切换后所有入口、详情、空状态、弹层、底部导航和顶部导航都属于同一书房世界观。
- 每个模块有明显专属视觉，不是首页换标题。
- 页面结构可不同，但业务路径、真实数据和性能规则不变。
- 所有设计通过后再实现主题入口与运行时代码。
