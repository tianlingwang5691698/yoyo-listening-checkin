# 佑声英语 8.0.0 发布摘要

发布日期：2026-07-11

## 账号、设置与权限

- “我的”统一收口为“设置”，包含家庭与账号、外观主题和中文简体 / English。
- 学生与家长均可维护自己的昵称；家长绑定学生后按当前学生 target 查看数据。
- 后台管理只对云端确认的管理员显示，普通用户没有入口。

## 双语与两套主题

- 首页、导航、学习模块、记录、提示、弹窗和广告海报完成中英文切换。
- 原题、文章、听力 transcript、中文释义和 AI 教学内容保持原内容。
- 雾蓝玻璃与静谧图书馆均完成英文防溢出、按钮居中和单词不拆行处理。
- 页面切换先同步主题色，避免导航栏短暂闪出上一主题颜色。

## 性能与数据准确性

- 缓存首屏目标 `<200ms`；无缓存目标 `<600ms`、硬上限 `<800ms`。
- 首页、成长页和学习目录使用轻量摘要、快照首显、云端后台刷新和单条按 ID 加载。
- 修改自定义听力计划后，首页目标时长改用当前任务实时汇总，不再沿用更新时间更早的旧日报快照。
- 成长累计听力按 `familyId + childId` 独立统计；学生本人及家长切换目标均读取对应学生数据。
- 成长页本地快照只负责快速首显，最终统计强制以云端 dashboard 为准；同步前不展示假 0。
- 累计听力时长不依赖本地/线上表现不一致的聚合 SDK，统一按日报轻字段分页读取、按日期去重求和。
- 真机验证：学生 986209 为 10 分钟，家长绑定 317613 为 57 小时 33 分钟。

## 阅读、语法、听力与写作

- 阅读、语法、听力和写作均采用稳定内容 ID、按需详情和缓存优先的 AI 结果链路。
- 已生成的公共解析供学生快速复用；个人“重新讲 / 重新解析”只更新本人记录。
- 阅读提交后自动续接 AI 解析，历史记录按 `attemptId` 精确读取，不再停留在“生成解析中”。
- 阅读练习记录自动补读云端解析，并为超时、缓存缺失和 target 错位提供 DEBUG 链路。
- 阅读错题集保存“原文章 + 错题”；旧错题按文章 ID 回源补原文。
- 阅读模块迁入普通分包，主包保持 2MB 限制内，页面路径不变。

## 词汇与完成反馈

- 词汇新学和复习按学生、词库、日期累计扣减；当天完成后不重复增加计数。
- 学生增加计划额度后只补差额，完成新增额度可再次获得完成反馈。
- 完成当日额度后默认复习当日全部单词，也可调整数量；不再增加学习计数或奖励次数。
- 当日重复复习页使用内存数据先渲染，音频预读后置，独立按 `<200ms` 首屏目标监测。
- 完成页显示本次背诵与复习数量，中英文及两套主题一致。
- 阅读和词汇完成音效仅由学生真实完成触发，家长预览不写记录、不播放奖励。

## 发布与兼容

- 小程序前端版本：`8.0.0`。
- `yoyo` 云函数版本：`8.0.0`，需与本次小程序包一起部署。
- `unlock1-preprocess` 本次无需重新部署。
- 未新增数据库集合；阅读错题仅在现有错题记录中增加兼容字段 `sourcePassage`。
- 线上内容上传继续遵循增量规则，不覆盖、删除或重命名已有可用内容。
