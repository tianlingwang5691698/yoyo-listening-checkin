# 阅读详情端口说明

## 端口范围

- 页面：`pages/reading/detail/index`
- 云函数：`getReadingPassage`、`getReadingStudyPack`、`submitReadingAttempt`、`synthesizeReadingAudio`
- 数据：`readingAttempts`、`readingStudyPacks`、本地 `readingStudyPack:*`

## 修改前必读

1. 本文件。
2. `docs/ports/README.md`。
3. `cloudfunctions/yoyo/services/reading.service.js` 中阅读学习包生成和校验逻辑。
4. `docs/PRODUCT_DESIGN_RULES.md`、`docs/DESIGN_STYLE_REQUIREMENTS.md`。
5. `docs/WECHAT_MINIPROGRAM_UI_FORMAT.md`。

## 产品要求

- 阅读提交后生成判分、正确答案、逐题答案句和中文解析，不生成全文翻译。
- 生词卡、短语卡、句型卡作为第二轮学习卡一起生成；点其中任意入口就生成三类卡。
- 原文句子支持按需点击翻译；只翻译当前句子，不生成全文翻译。
- 逐题解析必须按真实题号展示，答案句必须是原文直接依据。
- 生词优先中考常见但学生可能不熟的词，例句来自原文或贴近原文。
- 句型卡必须有中文解释和例句。
- 学习包内容要进入复习能力，不只做一次性展示。
- 页面语言保持极简，不写长说明。
