# 阅读模块：图书馆静谧主题逐页设计规范

## 1. 设计边界

- 主题：`themeId=library`，显示名“图书馆静谧”；`warm / 雾蓝玻璃`继续为默认主题。
- `pageSkin`：目录页 `library-reading-catalogue`；详情页 `library-reading-desk`。
- 真实页面仅有 `pages/reading/index`、`pages/reading/detail/index`。
- 共用现有请求、快照、路由、题型、提交、学习包、查词和身份权限；不得复制业务逻辑。
- 目录只展示云端真实分组、区、篇目和题量；不新增“今日阅读”、推荐、排行或虚构进度。
- 视觉板中的“2019 上海长宁二模阅读 A”为项目真实样本标题；生成器自动排出的数量、分数及英文正文均仅为布局占位，不是产品数据，实施时必须由现有真实字段替换，且视觉板不进入代码或上传包。

## 2. 模块叙事与图案

阅读是一张从馆藏索引中取出、摊在阅读灯下批注的试卷。

- 目录页独有图案：馆藏总目录册、分区抽屉标签、试卷书脊号、页码角签。
- 详情页独有图案：跨栏书页、左侧批注线、答案索引签、校对符号、页边题号。
- 禁止复用听力声波、语法结构连线、词汇抽认卡堆，也不把所有内容做成圆角卡片列表。
- 圆角只用于纸张自然卷角和小弹层，最大 `8px`；主纸页可为 `2px 8px 8px 2px`。

## 3. 真实业务与路由

| 页面 | 真实入口与层级 | 真实主动作 | 真实后续 |
| --- | --- | --- | --- |
| 阅读目录 | 首页阅读入口进入 `pages/reading/index`；根目录 → 一模/二模/真题卷 → 区 → 篇目 | 点整行进入下一层或篇目 | `navigateTo('/pages/reading/detail/index?passageId=...')` |
| 阅读详情 | 接收 `passageId`，优先读 `readingPassageSnapshotV1`，再回源 | 未提交时仅“提交阅读” | 提交后显示结果、逐题解析、高亮、学习包、查词 |

目录页右滑返回上一级、面包屑返回根/考试层级的行为保持不变。家长模式沿用现有“试做完成”结果，不制造学生学习记录。

### 4.1 基础 Token

| Token | 值 | 用途 |

| `--lib-bg-room` | `#2B211B` | 顶部书房空间、深色场景边缘 |
| `--lib-bg-paper` | `#FAF5EA` | 主阅读纸面 |
| `--lib-bg-paper-muted` | `#F3E8D4` | 目录册、次级纸张、空状态 |
| `--lib-panel-ink` | `#14283A` | 顶部导航、索引抽屉、完成结果条 |
| `--lib-accent-brass` | `#B89562` | 当前索引、主动作、页码、选中态 |
| `--lib-accent-moss` | `#7F8C78` | 正确、完成、已加入 |
| `--lib-text-primary` | `#2B211B` | 纸面标题与正文 |
| `--lib-text-secondary` | `#6F675F` | 元信息、说明、未选状态 |
| `--lib-error` | `#9A5F55` | 错误、订正，禁止大面积铺色 |
| `--lib-rule` | `rgba(184,149,98,.42)` | 黄铜细线、页边线 |
| `--lib-paper-shadow` | `0 6px 18px rgba(43,33,27,.14)` | 纸张短柔阴影 |

| `--lib-radius-control` | `6px` | 按钮、选项、索引签 |

### 4.2 字体与尺寸

- 页标题：系统宋体回退 `Songti SC, STSong, serif`，`28px/1.2`，字重 600。
- 文章标题：同一衬线栈，`22px/1.35`；英文正文使用系统无衬线，`17px/1.82`。
- 题目与选项：系统无衬线，`15-16px/1.55`；元信息 `12px/1.4`。
- 字距统一 `0`；正文宽度优先保证每行约 38-52 个英文字符。
- 控件最小点击高度 `44px`；底部主动作避开安全区。

### 4.3 状态色

- 选中：羊皮纸底 + 左侧黄铜线，不整块深色反转。
- 正确：苔藓绿细下划线、校对勾或窄边注。
- 错误：砖红校对线和“订正”，不使用高饱和红底。
- 高亮：答案句为淡黄铜底，生词为淡苔藓底，短语为淡墨蓝灰底，句型为羊皮纸压线。

## 5. `pages/reading/index`：馆藏目录

### 5.1 首屏结构

1. **融合导航**：墨水蓝窄顶栏，标题“阅读”；下方不是雾蓝 Hero 卡，而是一张露出书脊的总目录册。
2. **目录册扉页**：真实文案“中考阅读 / 选择一篇好好读 / 一模、二模、真题卷”；右侧是三层纸页和黄铜页码签。
3. **当前目录层**：首屏直接开始真实目录，不增加统计 Hero。标题为 `selectedHeader`，右侧只显示根层 `categoryRoot.count 篇` 或“‹ 上一级”。
4. **唯一强动作**：当前可进入的整行目录项；不再放独立“开始阅读”按钮。

### 5.2 三层目录形态

#### 根层 `isRootLevel`

- 将一模、二模、真题卷做成同一册中的三张**跨栏目录页**，不是三张悬浮卡。
- 左栏为竖排考试层级签，右栏显示 `item.label` 与 `item.districts.length 个区 · item.count 篇`。
- 整行点击 `selectExamType`；黄铜页码角提示可进入。

#### 考试层 `isExamLevel`

- 面包屑使用页眉小字“中考阅读 / {{selectedGroup.label}}”。
- 各区表现为木质目录柜中的**纸质抽屉签**，一行一签，左侧窄色签而非卡片图标。
- `completionReady` 时显示 `completedCount / count 已完成`，否则只显示 `count 篇`；不前端推测完成数。
- 整行点击 `selectDistrict`。

#### 区域层 `isDistrictLevel`

- 标题使用真实 `{{selectedGroup.label}} · {{selectedDistrictNode.label}}`。
- 篇目改为**装订试卷索引**：左侧页码 `index + 1`，中间 `title / meta · questionCount 题`，右侧答案索引签显示“进入 / 练习 / 复习”。
- `completed` 仅改变索引签为苔藓绿，不改变路由与行高。

### 5.3 状态规范

| 状态 | 触发字段/链路 | 呈现 |
| --- | --- | --- |
| 加载 | `loading=true` 且无快照 | 保留目录册扉页；内容区显示 3 行纸页骨架和“正在取阅目录”，不显示假标题/数量。 |
| 快照刷新 | 已有 `readingHomeSnapshotV1`，后台刷新 | 真实目录立即可点；页眉黄铜小点轻呼吸，不遮挡操作，不清空旧目录。 |
| 空 | `loading=false && !categoryRoot` | 一张合拢的空目录册，真实文案“暂无阅读内容。”；无主按钮。 |
| 正常 | `categoryRoot` | 按根/考试/区域层展示；每屏仅整行进入为强动作。 |
| 完成信息 | `completionReady` / `completed` | 区层显示完成比，篇目签显示“复习”；根层不请求或汇总全量完成态。 |
| 错误 | 无快照且 `syncMode=cloud-error`，或 `loadDirectory` 异常 | 内容区砖红边注“目录加载失败”，唯一动作“重试”；开发调试期按项目规则附具体链路点，确认后撤掉。 |

### 5.4 控件与交互

- 返回：保留“‹ 上一级”、面包屑点击和右滑返回；三者落到同一现有方法。
- 目录项：整行按压下沉 `1px`，纸张阴影收短，时长约 `220ms`。
- 箭头使用细黄铜书签尖角，不做圆形按钮。
- 滚动时目录册扉页正常离屏，不做粘性大 Hero。

## 6. `pages/reading/detail/index`：批注阅读台

### 6.1 未提交首屏

1. **融合导航**：“阅读练习”，墨水蓝短栏与木桌背景相接。
2. **摊开正文**：单张纵向纸页占首屏主体，页眉显示真实 `year · district · examType · sectionDisplay · difficultyDisplay`，标题为真实 `passage.title`。
3. **正文**：连续排版，不把每句做卡片；左侧批注线、右下页码角。首字母填空直接嵌在正文下划线位置。
4. **题目**：普通阅读题作为正文右侧批注在移动端下移成页边题注；题号通过黄铜定位线与正文视觉关联。
5. **唯一强动作**：页面尾部“提交阅读”；未答完沿用“先完成题目”轻提示。

### 6.2 题型差异

- **选择题**：A-D 为左侧窄索引栏，选项正文为无卡片的分隔行；选中态使用黄铜左线。
- **填空题**：使用纸面横线输入；提交后在其下显示“正确答案：…”；不做输入框胶囊。
- **首字母填空 C**：空位嵌入连续原文；提交后另起“逐题订正”校样页，保持真实层级：题号/状态 → 你的答案/正确答案 → 解析 → 答案句。

### 6.3 提交中与错误

- `submitting=true`：主按钮原位变为“生成解析中”，显示黄铜细进度线；锁定选项/输入，保持正文与答案不跳动。
- 未答完：只显示现有 toast“先完成题目”，不新增弹窗。
- `analysisErrorText`：在主按钮下显示纸质砖红校对条“解析生成失败，可重试。”，唯一动作“重试”。

### 6.4 完成/解析态

- `submitted=true` 后移除提交按钮，正文顶部出现**答案索引条**：原文、生词、短语、答案句、句型、全部。
- 结果不是普通卡片：使用夹在正文与题目之间的墨蓝**借阅回执**，显示 `scoreText` 或“已完成”，以及 `reviewSummary`。
- `readingCelebrating` 只允许黄铜扫光和两个微小校对点；保留现有一次性完成音与 `Nice reading.`，不做礼花。
- 普通阅读题在原题下原位展开“解析 / 正确或订正 / 答案句 / 翻译”。
- 长按句子沿用行内“翻译中...”与译文；提交前不启用。
- 提交后英文单词可轻点查词，提交前不启用。

### 6.5 学习包

- 学习包是正文后的**三分索引册**，保留“生词 / 短语 / 句型”三栏和现有按需生成逻辑。
- 每项采用批注条目，不做同款大卡：序号、英文标题、音标/释义、例句、中文解释分层。
- 生词与短语保留 `♪` 发音；句型不显示发音。
- 每项右侧“加入 / 已加入”为轻操作；整页强动作仍只在未提交时是“提交阅读”。
- 空项沿用“还没有生成生词/短语/句型。”与“生成生词/短语/句型”；生成中沿用“生词生成中”等真实文案。
- `studyErrorText` 使用小型砖红批注条，动作“重试”。

### 6.6 词典弹层

- 保留底部弹层，不新增页面或路由。
- 形态为从桌边抽出的**词典索引页**：词、音标、释义；右上 `♪`，主动作“加入词库”。
- 加载时保留词头位置，释义区显示纸面骨架；失败沿用“查词失败”toast。
- 遮罩为低透明墨水蓝，弹层圆角不超过 `8px`。

### 6.7 状态规范

| 状态 | 触发字段/链路 | 呈现 |
| --- | --- | --- |
| 加载 | `loading=true && !passage` | 空阅读台 + 一张真实比例纸页骨架；文案“正在取阅文章”，不渲染假题。 |
| 快照首显 | 命中 `readingPassageSnapshotV1` | 先显示真实正文与题目；后台补 `latestAttempt`，不遮挡首动作。 |
| 空 | `loading=false && !passage` | 合起的试卷夹 + 现有文案“暂无阅读内容。”；无按钮。 |
| 正常答题 | `passage && !submitted` | 正文、题目、唯一主动作“提交阅读”。 |
| 提交中 | `submitting=true` | 锁定答案，按钮“生成解析中”，不提前播放完成反馈。 |
| 完成 | `submitted=true` | 借阅回执、答案索引、逐题解析、学习包；家长为“试做完成”。 |
| 学习包加载 | `loadingStudySection` | 当前索引签轻呼吸，空项显示“生词/短语/句型生成中”。 |
| 解析错误 | `analysisErrorText` | 砖红校对条 +“重试”；保留已填写答案。 |
| 学习包错误 | `studyErrorText` | 对应索引册内显示“生成失败，可重试。” +“重试”。 |
| 查词加载/错误 | `dictionaryLoading` / 请求失败 | 词典页骨架；失败 toast“查词失败”，正文位置不变。 |

## 7. 与雾蓝玻璃主题的结构差异

| 雾蓝玻璃当前结构 | 图书馆静谧结构 |
| --- | --- |
| 圆角玻璃 Hero + 悬浮书页图形 | 总目录册扉页直接成为导航后的内容，不使用玻璃容器 |
| 根层、区层、篇目均为圆角列表卡 | 根层跨栏目录页、区层抽屉签、篇目装订索引，三层结构不同 |
| 雾蓝渐变与大面积玻璃背景 | 木桌空间只做边缘，主阅读区以羊皮纸和墨蓝索引承载 |
| 详情正文、题目、结果、学习包均为圆角卡片 | 正文是连续纸页，题目是页边题注，结果是借阅回执，学习包是索引册 |
| 珊瑚渐变胶囊主按钮 | 墨蓝矩形按钮 + 1px 黄铜内线，`6px` 圆角 |
| 高亮为彩色软底块 | 高亮像荧光批注与校对线，答案句带页边索引签 |
| 词典为玻璃底部 Sheet | 词典为抽出的纸质索引页 |

## 8. 实施注意点

1. WXML 主题分支只能重排现有字段与控件；请求仍由 `onShow/onLoad/applyReadingHome/applyPassage` 等现有逻辑驱动，路由和 `passageId` 不变。
2. 目录首屏继续 `directoryOnly: true`，不把正文或全量完成态带回首屏；快照存在时不得先清空。详情快照只承接真实 passage，完成态以后端 `latestAttempt.review.analysis` 为准。
3. 主题样式优先由 `theme-library` 与上述 token 覆盖；主按钮、选项、词典、底部安全区尺寸稳定。任何调试链路只在异常测试期显示，修复确认后撤掉。

> 视觉板只评审结构、材质与信息层级。受图像生成文字精度限制，板内数量、分数和英文正文视为明确的布局占位；真实界面不得照录，必须绑定目录、篇目、题目、作答与解析的现有返回字段。
