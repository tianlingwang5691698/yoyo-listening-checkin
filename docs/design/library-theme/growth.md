# 图书馆静谧主题：成长模块设计规范

## 1. 范围与真实业务

- 主题：`themeId=library`，显示名“图书馆静谧”；`warm / 雾蓝玻璃` 保持默认。
- 页面：`pages/record/index`、`pages/home/completed/index`。
- 入口：底部导航“成长”进入记录页；首页“今日听力”完成后可进入今日完成页。
- 真实数据口径：`stats.streakDays`、`stats.completedDays`、`stats.completedTasks`、`stats.totalMinutes`、当前月 `heatmap`、`selectedDayReport.items`、今日完成 `items`。
- 不新增等级、排名、成长值、预测、勋章、阅读量等不存在指标。视觉板数字和条目只作布局占位，实施时必须来自现有字段。

## 2. 主题叙事与图案

成长模块是一份孩子在图书馆里的长期借阅档案：总览是借阅记录册，日期是索引页，日记录是成长档案袋，今日完成是当天归还单。禁止雾蓝玻璃、仪表盘圆环、后台报表卡片。

- 模块图案：馆藏借阅记录、日期索引、成长档案、日历压印、书签轨迹。
- 首屏只展示真实核心统计和本月热力，不抢先加载当天详情、近 7 天、作文、追赶任务。
- 每页一个强动作：记录页为日期记录里的“查看”；追赶仅在可追赶且用户点击后加载；今日完成页为整条记录“查看任务/解析/批改/回答”。
- 错误态用低饱和砖红馆藏校验单；测试期保留可复制 debug 链路，修复后撤掉。

## 3. `pages/record/index`：成长档案

### 首屏结构

1. 融合导航：深胡桃木书架背景，标题“成长轨迹”，右侧同步章显示“已同步 / 本地状态”。
2. 借阅记录册：羊皮纸册页展示 `连续 / 累计` 切换。主数字只绑定 `heroMetricValue`，标签为 `连续打卡天 / 累计打卡天`。
3. 账页三栏：`累计天数`、`累计时长`、`完成任务`，分别来自 `completedDays`、`totalDurationText`、`completedTasks`。累计时长无来源时显示真实 `0分钟`。
4. 日期索引月历：当前月 `monthCells` 是一本打开的日期索引册；点亮格为苔藓绿压印，选中日为黄铜书签框，今日为墨蓝细线。
5. 成长档案袋：选中日期先显示摘要 `selectedDaySummary`；未点“查看”前不拉完整详情。

### 详情与追赶

- “查看”触发 `loadSelectedDay` 后，档案袋展开 `selectedDayReport.items`。
- 听力/口语条目保留 `playCount / repeatTarget`、`timeLines`、回答次数和最近分数；阅读、语法、写作、词汇条目保留 `progressText` 或对应详情入口。
- 口语展开显示真实问题、回答、反馈、分项分数与播放按钮。
- 追赶任务区域只在 `catchupState.canCatchup` 时出现可点借阅条；点击后才显示 `catchupTasks`，不进入首屏链路。

### 状态

| 状态 | 呈现 |
| --- | --- |
| 加载 | 命中 `recordHomeSnapshotV1` 时直接显示快照；无快照时保留借阅记录册、三栏账页和空日期索引骨架，不显示假数据或全屏等待。 |
| 无数据 | `stats` 和 `heatmap` 均为 0 时，记录册数字按真实 0 展示；月历为空压印；选中日档案袋显示“这一天还没有记录。” |
| 正常 | 展示真实统计、当前月热力、选中日摘要；完整日记录按“查看”加载。 |
| 离线 | 有快照时继续显示最近记录，右上同步章为“本地状态”，日期索引底部用小字“正在使用最近内容”；不清空月历。 |
| 错误 | 无可用快照且 dashboard 或 heatmap 失败时，记录册下方显示砖红“馆藏校验单”，保留 `recordDebugLines`；月历维持空骨架，动作只保留重试或稍后再试语义。 |
| 完成/里程碑 | `streakMilestoneVisible` 只做黄铜馆藏章轻压印，文案使用 `连续 n 天`；不做礼花或新增奖励数据。 |

## 4. `pages/home/completed/index`：今日归还单

### 首屏结构

1. 顶部归还单：标题“今日完成”，副标题 `{{items.length}} 项已完成`，右侧小馆藏章显示真实 `items.length`。
2. 当日借阅条：`items` 纵向或横向都可，但形态为纸质归还单，不做玻璃成果卡。
3. 每条记录：左侧馆藏序号 `item.index`，中间 `typeLabel / title / meta / progressText`，右侧使用真实 `actionText`。
4. 详情展开：口语沿用当前页展开；阅读、语法、写作跳到家长详情；听力写入 `lessonTaskSnapshotV1` 后进课程回看。

### 状态

| 状态 | 呈现 |
| --- | --- |
| 加载 | 先读 `todayCompletedItemsV1` 缓存；无缓存时显示归还单轮廓和 2 条无文字纸纹，不写“加载中”。 |
| 无数据 | `items.length === 0` 时显示真实文案“今天还没有完成记录。”；不显示建议任务或虚构完成项。 |
| 正常 | 使用 `items.length` 和真实条目，分类仅来自 `getTypeLabel`：听力、阅读、阅读学习、语法、写作、回答、听力学习包、词汇。 |
| 离线 | 有缓存时保留缓存归还单；右上角用小章标记“本地状态”，不再请求覆盖为空。 |
| 错误 | `scope=listening` 缓存缺失或过滤异常时，归还单下方展示 `debugLines`，低饱和砖红细边；无调试信息时只保留空态。 |
| 完成详情 | 口语展开显示真实分数、问题、回答、反馈和播放按钮；其他类型只使用现有跳转动作，不在本页拼装不存在的详情。 |

## 5. Token 与组件

| Token | 值 | 用途 |
| --- | --- | --- |
| `--lib-growth-wood` | `#2B211B` | 书架、导航、页面深层背景 |
| `--lib-growth-ink` | `#14283A` | 主标题、强动作、同步章深色 |
| `--lib-growth-paper` | `#FAF5EA` | 借阅记录册、归还单 |
| `--lib-growth-paper-muted` | `#F3E8D4` | 日期索引、档案袋内页 |
| `--lib-growth-brass` | `#B89562` | 书签框、日期选中、刻线 |
| `--lib-growth-moss` | `#7F8C78` | 完成日、已完成状态 |
| `--lib-growth-muted` | `#6F675F` | 次级文字 |
| `--lib-growth-error` | `#9A5E52` | 调试校验单、错误边注 |
| `--lib-growth-rule` | `rgba(184,149,98,.42)` | 黄铜细线 |
| `--lib-growth-shadow` | `0 4px 14px rgba(43,33,27,.16)` | 纸张短柔阴影 |

- 圆角：主纸页 `6px`，按钮/索引签 `6px`，日期格 `4px`；不使用大胶囊和圆形仪表。
- 字体：标题用系统宋体回退；统计数字可高权重但只用于真实核心数字；正文和记录条用系统无衬线。
- 动效：日期选中为书签压下 `160ms`；档案袋展开 `200ms`；里程碑为馆藏章一次压印，不循环。

## 6. 性能与实施注意

1. 记录页继续遵循现有链路：先快照/月历缓存，再并发 `getDashboard(view=record)` 与 `getMonthHeatmap`；当天详情、相邻月份、追赶任务延后。
2. 快照必须带当前 target；target 不一致时不能首显旧记录。热力兜底只能补天数和任务数，不能编造时长。
3. 今日完成页 `scope=listening` 时不调用 `getStudyCompletions`，只用当前缓存和 debug；其他 scope 才后台刷新。
4. 测试阶段错误必须写清 `pages/record` 或 `pages/home/completed` 到 store、cloud action、关键字段和 target；确认修复后撤掉 debug。
5. 本设计仅新增文档和评审图；实施 UI 代码时需另行追加 `docs/UI_DESIGN_LANGUAGE_LOG.md`。

## 7. 与雾蓝玻璃的结构差异

| 当前雾蓝结构 | 图书馆静谧结构 |
| --- | --- |
| 玻璃 hero、圆环、轨迹卡、报告卡 | 借阅记录册、日期索引册、成长档案袋 |
| 大面积雾蓝渐变和漂浮光效 | 胡桃木书桌、羊皮纸、黄铜刻线 |
| 横向成果卡组 | 当日归还单和馆藏序号 |
| 报表式状态 badge | 同步章、馆藏章、校验单 |
| 同类圆角卡堆叠 | 账页、索引、档案袋三种层级 |

## 8. 视觉板覆盖

`growth-board.png` 使用 2 x 3 手机屏高保真评审板：

1. 成长档案正常首屏：借阅记录册、真实统计口径、日期索引月历。
2. 选中日期摘要与详情：档案袋先摘要，点击后展开真实任务记录。
3. 加载与离线：快照首显、本地状态章、日期索引骨架。
4. 无数据与错误：0 统计、空月历、“这一天还没有记录。”、砖红调试校验单。
5. 追赶与里程碑：可追赶借阅条、`连续 n 天` 馆藏章。
6. 今日归还单：今日完成正常、空态、口语展开与 debug 小样。
