# 语法模块「图书馆静谧」逐页设计规范

## 1. 设计边界

- 主题：`themeId=library`，显示名“图书馆静谧”；`warm / 雾蓝玻璃` 保持默认。
- 页面：`pages/grammar/index`，不新增路由。现有 `mode`、目录选择、答题、讲解、错题、查词与进度逻辑全部复用。
- 真实路径：考点分类/错题集 -> 初中/高中 -> 二模/一模 -> 考点大类 -> 细分考点 -> 逐题练习 -> 答案反馈 -> 看讲解/重新讲。
- 首屏只读取一模、二模目录与题量；题目正文、进度和错题集仍在点击后按需加载。
- 模块意象：句子排版台、主谓宾字模、语法校样符号、结构连线。禁止网络节点、后台诊断图、通用声波与大圆环。

字体：页面标题使用系统衬线回退；题干、选项、解析使用系统无衬线。数字不使用等宽字体。所有 letter-spacing 为 `0`。

## 3. 全局首屏骨架

1. 融合式顶部导航：米白“语法”，不另做悬浮导航卡。
2. 句子排版台：深胡桃木横台上固定展示“主语 — 谓语 — 宾语”三枚纸质字模；黄铜结构线在文字下方，不遮字。标题沿用“把一句话讲明白”，说明沿用现有真实文案。
3. 模式切换：`考点分类 / 错题集` 做成两枚书目索引签，选中项为黄铜下划线，不做胶囊分段器。

顶部排版台只负责模块识别，不承担点击。进入练习后压缩为 112rpx 高的“校样页眉”，让题干成为首屏主角。

## 4. 状态 A：目录首页

### 首屏结构

- 主标题区下接一张无外层卡的“语法目录页”，左侧竖排书目号，右侧为阶段条目。
- 条目使用跨页目录行，不做宫格卡：`初中 / 题量 / ›`、`高中 / 0 题 / ›`，均来自 `stages`。
- 当前唯一强动作是整行点击阶段；不额外放“进入”按钮。
- `错题集` 模式仅把目录眉题改为“错题难度”，数据来自 `getGrammarWrongBook`，不制造错题数量。

### 状态

- 加载：保留排版台与索引签；目录纸显示 2 条固定高度的纸纹骨架，不显示假标题或假题量。
- 空：考点分类为空时显示“语法目录暂不可用”；错题集为空时显示“还没有错题”，强动作回到“考点分类”。
- 正常：展示真实阶段和题量；`高中 0 题` 保留真实状态，视觉降级但仍按现有整行行为处理。
- 完成：目录首页无独立业务完成态；完成痕迹仅由进入具体考点后的真实进度承接，不新增统计。
- 错误：目录纸顶部嵌一条低饱和砖红校样批注“语法目录加载失败”，唯一强动作“重新加载”；测试阶段同时标出 `pages/grammar/index.js:onLoad -> store.getGrammarHome(em1/em2)` 链路位置，修复后撤除。

### 独有图案与交互

- 页码点、细黄铜引导线、`S / V / O` 小型校样符号。
- 行按压仅下沉 1rpx；点击后原位纸张向左错开 8rpx，再切换下一层，时长 180ms。

## 5. 状态 B：模考与考点目录

### 首屏结构

- 面包屑写在纸张页眉：`初中 · 模考`、`初中 · 二模` 或真实 `selectedCategory.topic`。
- 返回使用页眉左侧细箭头与真实文案“难度 / 模考 / 大类”，不做按钮胶囊。
- 模考层：`二模`、`一模` 两条书目页签，右侧显示真实题量。
- 大类层：考点大类采用“索引页双栏”，每项是带序号的排版条，不是独立卡片。二模真实目录示例为 `动词类 649题 / 词法类 900题 / 从句类 121题 / 句型结构类 230题 / 连词逻辑类 160题 / 情景交际类 92题`。
- 细分层：改为单栏“抽屉索引签”，突出考点名称与题量，避免与大类层同构。
- 每层唯一强动作都是整行进入下一层。

### 状态

- 加载：点击一模或考点时，保留当前目录，目标行右侧黄铜页码点缓慢移动；不清空当前内容。
- 空：模考无条目显示“该阶段暂无语法练习”；大类/细分无条目显示“该分类暂无考点”，唯一动作返回上一层。
- 正常：严格使用 `exam/topic/count`；长考点名自动换行，题量不挤压标题。
- 完成：该层不推断完成率，不增加勾选或进度条。
- 错误：一模失败沿用真实文案“一模语法加载失败”；页内追加可重试校样签。测试断点为 `ensureExamLoaded -> store.getGrammarHome({ examId: 'em1' })`。

### 独有图案

- 模考层：年份卷宗压印。
- 大类层：主谓宾字模组合与校样括号。
- 细分层：句法树只画短结构线，不出现复杂节点图。

## 6. 状态 C：练习与提交反馈

### 首屏结构

- 顶部压缩页眉：真实考点名、`answeredCount / selectedQuestions.length`、返回“细分”。
- 进度只保留页边黄铜刻线，不再做胶囊数字；恢复进度时显示真实文案“已自动接着第 N 题开始。”
- 题目改为一张连续“校样长页”，题与题之间用压线分隔，避免每题一张卡。
- 题头保留真实信息：`第 N 题 · 年份 · 地区 · 原卷第 N 题`。
- 视觉板练习题取自真实题库：`第 1 题 · 2012 · 奉贤 · 原卷第 31 题`，题干 `Would you please help me pick up ____umbrella on the floor?`，选项 `A a / B an / C the / D /`，答案 `C`。
- 选项采用四枚可点击活字条，短选项双栏，长文本允许跨整行。当前唯一强动作是选择一个答案，选择即提交，保持现有逻辑。

### 未作答

- 题干为墨水蓝；A-D 置于黄铜小方签中。
- 不展示词典点击样式，保持现有“答后可查词”规则。

### 已提交

- 正确：标准答案活字条盖苔藓绿“校对通过”细印；反馈仍显示“答对了 · 标准答案：X”。
- 错误：学生答案加砖红校样删除线，正确答案加苔藓绿下划线；反馈仍显示“答错了 · 标准答案：X”。禁止整块鲜红背景。
- 提交后唯一强动作切换为“看讲解”。“重新讲”为解析区内次级文字动作。
- 提交后英文 token 出现黄铜虚线下划线，点击打开真实查词抽屉。

### 状态

- 加载：有题目快照时先显示快照；远端题目/进度补齐时只在页边显示移动书签。无快照时显示一张固定高度题纸骨架。
- 空/完成：`selectedQuestions.length === 0` 使用真实文案“本考点已做完。”，画面为合上的校样夹与苔藓绿完成章；唯一动作返回“细分”。
- 正常：可连续作答；每 3 题沿用现有记录与进度写入，不增加可见后台指标。
- 错误：题目正文加载失败时显示“题目暂不可用，请稍后再试”，保留返回路径；测试断点标明 `selectTopic -> getGrammarTopic/getGrammarProgress`。

## 7. 状态 D：解析

### 首屏结构

- 解析在原题下方展开为“编辑批注边栏”，不新增结果页，不遮挡原题和选项。
- 标题使用真实 `explanation.topic`，右侧保留“答案 X”。
- 正文依次展示真实 `explanation.explanation` 与可选 `elimination`。
- 解析载入时，“看讲解”位置替换为三枚移动校样点，页面不跳动。
- 唯一次级命令为“重新讲”；本状态的强视觉焦点是解析正文，不再放主按钮。

### 状态

- 加载：批注边栏展开到稳定最小高度，显示纸纹骨架。
- 正常：解析与排除说明分段，行宽控制在易读范围。
- 完成：解析出现即视为该题反馈完整；不新增庆祝页或分数汇总。
- 错误：沿用“讲解暂不可用，请稍后再试。”；若已有真实 `cloudError.message`，仅测试态在批注脚注显示链路，正式态不暴露技术文本。唯一动作“重新讲”。

## 8. 状态 E：查词抽屉

- 保持答后点击英文词进入；底部抽屉像拉出的纸质词典索引卡，不使用玻璃弹层。
- 顶部显示真实 `word / phonetic`；发音使用音符图标；唯一强动作“加入词库”。
- 加载：词头立即出现，释义显示两行纸纹骨架；发音与加入按钮维持稳定尺寸。
- 空：沿用“暂无释义。”；仍允许加入词库。
- 正常：逐条展示真实 definitions。
- 完成：使用现有 toast“已加入词库”，按钮短暂盖苔藓绿“已收录”印记，不新增页面。
- 错误：沿用“词典暂不可用 / 加入失败 / 播放失败，稍后再试”。测试断点分别对应 `lookupWord / addDictionaryWord / playDictionaryWord`，修复后撤除。

## 9. 与“雾蓝玻璃”的结构差异

| 区域 | 雾蓝玻璃 | 图书馆静谧 |
| --- | --- | --- |
| Hero | 雾蓝玻璃卡 + 讲解板 | 与页面融合的深木排版台 + 纸质主谓宾字模 |
| 模式切换 | 圆角胶囊分段 | 书目索引签 + 黄铜下划线 |
| 阶段目录 | 不规则玻璃卡网格 | 连续书目目录页 |
| 大类目录 | 卡片式节点 | 双栏排版索引条 |
| 细分目录 | 同类节点卡 | 单栏抽屉索引签 |
| 练习 | 每题玻璃卡、选项网格 | 连续校样长页、活字选项条 |
| 对错 | 鼠尾草/珊瑚色块 | 校样章、删除线、下划线 |
| 解析 | 内嵌浅色分析卡 | 题旁编辑批注边栏 |
| 查词 | 白色玻璃底部 sheet | 纸质词典索引抽屉 |

## 10. 实施注意点

- 仅新增 `theme-library` + `pageSkin=grammar` 的呈现分支；不得复制 `onLoad/selectTopic/selectOption/loadExplanation` 等业务逻辑。
- 状态判断继续以现有字段为准：`mode`、各 selected id、`selectedQuestions`、`isAnswered/isCorrect/explaining/explanation`、dictionary 字段。
- 视觉稿的界面密度仅用于布局评审；规范中列出的题干、年份、地区、考点和题量均取自仓库真实语法数据，实现时仍只绑定线上返回值，不把示例写入页面。
- `主语 / 谓语 / 宾语` 必须位于最高文字层，装饰结构线不得穿过文字。
- 目录首屏不得请求题目正文或错题；快照存在时不得被空返回覆盖。
- 选项、发音、返回等控件设置稳定尺寸；长英文和长中文必须换行，不横向溢出。
- 错误链路信息只在测试阶段页内展示，按 `docs/ONLINE_DEBUG_DB_RULES.md` 修复确认后撤掉。
- 视觉板仅供评审，`grammar-board.png` 不进入小程序上传包。
