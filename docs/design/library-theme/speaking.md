# 图书馆静谧主题：口语模块逐页设计规范

## 1. 设计边界

- 主题：`themeId=library`，显示名“图书馆静谧”；`warm / 雾蓝玻璃` 继续为默认主题。
- 页面：`pages/speaking/index`，页面标题“口语”。
- 真实功能：短句选择、听问题、按住录音、松手后自动上传评分、显示本次总分与准确度/流利度/完整度。
- 真实本地题组：`句子跟读 / 校园表达 / 观点表达`，题干来自 `EXERCISES.prompt`；视觉板示例只作布局占位。
- 不新增历史记录、录音回放按钮、排行、推荐题、分数解释、转写文本或学习报告；这些能力不在当前页面数据里。

## 2. 模块叙事

口语模块是一张安静阅览室里的桌面录音台：学生在阅读灯下听题、看短句、按住黄铜麦克风回答，评分结果像老师在声纹边缘留下批注。

- 专属图案：阅览室口语角、桌面麦克风、呼吸刻度、声音回放槽、声纹批注。
- 禁止：通用卡片列表、雾蓝圆环、声波大背景、彩色仪表盘、虚构回放/历史数据。
- 页面只保留一个强动作：准备态为“按住回答”，播放问题为轻动作，评分完成后无新的强按钮。

## 4. 首屏入口：阅览室口语角

### 真实字段

- `activeExercise.title`
- `activeExercise.meta`
- `activeExercise.prompt`
- `exercises`
- `activeId`
- `questionPlaying`
- `questionLoading`
- `recording`
- `submitting`
- `tempFilePath`
- `recordDurationText`
- `result`
- `errorText`

### 首屏结构

1. 顶部融合导航：标题“口语练习”，副文案沿用“听清题目，按住回答。”；右侧为阅读灯照下的细线麦克风，不做大 hero 卡。
2. 今日题签：`今日题目`、英文题干、题组名与“听问题”。题签像摊开的借阅纸，左侧有黄铜装订线。
3. 题组选择：三条任务不是卡片网格，而是桌面上的三枚窄索引签；选中签露出黄铜书签线。
4. 录音台：中央为黄铜桌面麦克风，外圈是呼吸刻度；强动作“按住回答”固定在麦克风底座位置。
5. 状态线：沿用“准备录音 / 正在回答 / 已录制 x秒 / 正在评分”；表现为声纹批注，不额外弹层。

## 5. 录音准备态

- `recording=false && submitting=false && !tempFilePath && !result`。
- 麦克风静止，呼吸刻度只保留 12 个浅黄铜短线；不循环强动画。
- “听问题”是纸面右侧轻按钮：`准备播放 / 停止播放 / 听问题` 三态尺寸一致。
- 题组索引签整行可点，切换后清空本次临时录音和结果，符合现有 `selectExercise` 行为。
- 强动作只有“按住回答”；按钮为墨蓝底、黄铜内线、米白字，圆角不超过 6px。

## 6. 录音中

- `recording=true`。
- 桌面麦克风变为正在收音：黄铜呼吸刻度向外轻扩，声纹槽从底部出现 5 段细线，呼吸频率克制。
- 主按钮文案为“松手评分”，按钮位置和尺寸不变，只做轻微下沉。
- 题签、题组选择和听问题进入视觉降级，不允许播放问题抢占录音。
- 状态线显示“正在回答”，错误批注隐藏。

## 7. 已录制与评分中

- `tempFilePath` 存在时短暂显示“已录制 x秒”，随后现有逻辑自动进入 `submitPronunciation`。
- 当前独立页没有录音回放控件；“声音回放槽”只作为已录制声纹的视觉反馈，不新增播放录音按钮。
- `submitting=true` 时录音台改为校样状态：声纹槽被黄铜尺压住，文案“正在评分”，主按钮显示“评分中”且不可再次触发。
- 评分等待可能较长，界面必须稳定保留题干、题组和声纹，不显示伪进度百分比。
- 评分链路失败时不清空题目；错误批注显示“评分暂时没有成功，请稍后再试。”，强动作回到“按住回答”。

## 8. 结果态

- `result` 存在时，在录音台下方展开“声纹批注页”，不是另开结果页。
- 顶部显示真实 `result.score || 0` 与文案“本次结果”。
- 三项指标只显示真实字段：`accuracy`、`fluency`、`completion`；用三条竖向声纹批注尺表达百分比，不做圆形仪表盘。
- `resultCelebrating=true` 时只允许黄铜扫光和短促完成音；不使用彩屑、礼花或夸张动画。
- 结果态不增加“再练一次”按钮；用户若要重练，直接按住主麦克风即可，复用现有录音链路。

## 9. 权限失败、播放失败、空状态

### 权限/录音失败

- 当前页面错误入口为 `recorderManager.onError -> errorText='录音没有成功，请重新录一次。'`。
- 图书馆主题将错误显示为桌面边缘的砖红“录音批注”，不弹大遮罩；题目和主按钮保留。
- 若后续实现主动识别麦克风权限拒绝，仍只在本页提示并引导系统设置，不新增业务状态或假评分。

### 问题播放失败

- `questionAudioContext.onError` 或合成失败显示“问题播放失败，请稍后再试。”。
- “听问题”按钮恢复可点，录音主动作不受影响；错误批注位于题签下沿。

### 评分失败

- 显示“评分暂时没有成功，请稍后再试。”。
- 保留当前题目与题组；不展示空分数、不生成保底分、不假装提交成功。

### 空状态

- 虽然当前 `EXERCISES` 常量固定有 3 条，仍需防御 `exercises.length === 0 || !activeExercise`。
- 空态为合上的桌面麦克风盒，文案“暂无口语题目。”；隐藏听问题和录音动作，不造示例题。

### 加载态

- 页面无远端目录加载；只有问题音频合成与评分提交两个局部 loading。
- `questionLoading` 只影响“听问题”按钮；`submitting` 只影响录音台和状态线。不得把整页替换为骨架。

## 10. 与雾蓝玻璃的结构差异

| 雾蓝玻璃当前结构 | 图书馆静谧结构 |
|---|---|
| 玻璃舱、圆形声圈、珊瑚按住按钮 | 阅览桌录音台、黄铜桌面麦克风、墨蓝矩形主动作 |
| 三个任务为圆角网格节点 | 三枚窄索引签，像口语练习题签 |
| 声波与圆环集中在中央 | 呼吸刻度 + 声纹批注槽，强调安静录音 |
| 分数为三张小圆角指标卡 | 单张声纹批注页，三条批注尺 |
| 错误文字居中提示 | 桌边砖红校样批注，不遮挡主链路 |

## 11. 实施注意点

1. 只新增 `theme-library` / `pageSkin=speaking` 的呈现分支；不得复制 `startRecord`、`stopRecord`、`playQuestion`、`submitPronunciation` 等业务逻辑。
2. 录音、上传、评分仍使用现有 `store.createSpeakingUploadUrl`、`uploadSpeakingAudio`、`evaluateSpeakingPronunciation`；不得改变 `attemptType='standalone_sentence_repeat'`。
3. 页面没有远端题库与历史记录，视觉稿里的题目、声纹和分数均为布局占位；上线必须绑定现有字段。
4. 主按钮、听问题按钮、三项分数尺必须尺寸稳定；`准备播放 / 停止播放 / 评分中` 等长文案不得挤压。
5. 错误调试按线上调试规则处理：测试期可显示链路断点，评分成功后隐藏，不把 debug 带入正式状态。
6. 视觉板 `speaking-board.png` 仅用于评审，禁止进入小程序上传包。

## 12. 视觉板覆盖

`speaking-board.png` 使用 2 x 3 六屏评审板：

1. 入口准备态：阅览室口语角、今日题签、三枚题组索引签、桌面麦克风。
2. 听问题态：按钮为“停止播放”，题签下有轻微声纹。
3. 录音中：主按钮“松手评分”，呼吸刻度和声纹槽激活。
4. 已录制/评分中：显示“已录制 8秒 / 正在评分”，声纹被黄铜校样尺压住。
5. 结果态：本次结果、总分、准确度/流利度/完整度三条声纹批注尺。
6. 权限失败/空状态：录音失败批注、问题播放失败批注、暂无口语题目的合盒状态。
