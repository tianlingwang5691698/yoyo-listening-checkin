# 图书馆静谧主题：音频模块设计规范

## 1. 范围与真实路径

- 主题：`themeId=library`，显示名“图书馆静谧”；`warm / 雾蓝玻璃` 保持默认。
- 页面皮肤：`audio-catalog`（音频目录）、`audio-index`（听力组合）、`audio-turntable`（课程详情）。
- `pages/level/index`：音频总入口。真实动作是进入听力计划、查看固定计划、切换 `Pre A1–C2`、进入对应素材；素材实际路由为 `/pages/listening-material/index?levelId=&category=`。
- `pages/level-stage/index`：固定阶段或今日计划的组合索引。真实 phase 为 `round-1 / round-2 / round-3 / custom`；任务进入 `/pages/lesson/index?category=&taskId=`，预览任务附带 `planRunType=preview&planDayIndex=`。
- `pages/lesson/index`：播放、三遍进度、同步文本、文本学习包及真实口语分支；学生训练可写进度，家长与预览均不计入打卡。
- 不新增学习报告、搜索、收藏、下载、切歌、虚构曲目或额外路由。视觉板中的具体数量和曲名仅为布局占位，实施时只绑定现有数据。

## 2. 模块视觉母题

音频模块是私人书房里的声音档案室。入口页像唱片目录柜，组合页像抽出的章节索引册，课程页像摊在胡桃木桌面的唱机与纸带。三个页面共享“同一间书房”，但空间、信息密度和动作层级明显不同。

- 专属图案：唱片目录孔、磁带/音轨书脊、章节索引号、黄铜唱针、同心刻纹、纸带时间码。
- 禁止：雾蓝波形玻璃卡、轨道圆环泛用装饰、胶囊按钮海、每行重复按钮、所有内容都装进同款白卡。
- 页面只保留一个强动作：入口页为“设置计划”；组合页为当前可开始任务的整行点击；课程页为播放/暂停。展开、倍速、回退、查看文本、生成学习包等均为次级动作。

## 3. 主题 Token

| Token | 值 | 用途 |
| --- | --- | --- |
| `--library-bg` | `#FAF5EA` | 页面纸面底色 |
| `--library-wood` | `#2B211B` | 顶部场景、唱机底座、深色导航 |
| `--library-ink` | `#14283A` | 主文字、章节索引、播放器面板 |
| `--library-paper` | `#F3E8D4` | 目录纸、文本纸带、空状态 |
| `--library-brass` | `#B89562` | 唱针、选中线、主动作、当前进度 |
| `--library-moss` | `#7F8C78` | 完成态、已选、已生成 |
| `--library-muted` | `#6F675F` | 元信息、时间、说明 |
| `--library-error` | `#9A5548` | 低饱和错误文字和细线 |
| `--library-surface` | `#FFFCF5` | 清晰纸面 |
| `--library-line` | `rgba(184,149,98,.44)` | 黄铜细边、刻度 |
| `--library-shadow` | `0 8rpx 20rpx rgba(43,33,27,.12)` | 纸张与桌面的短柔阴影 |
| `--library-radius` | `8px` | 面板、抽屉、弹层最大常规圆角 |

- 标题使用系统宋体回退：`STSong, Songti SC, serif`；正文、按钮和时间使用系统无衬线。
- 时间和数字采用编辑排版感，字距固定为 `0`。
- 背景木纹只能低对比局部出现；文字承载面必须是清晰纸面或墨蓝实面。

## 4. `pages/level/index`：唱片目录台

### 首屏结构

1. 顶部为深胡桃木横向目录台，标题“音频”、副标题“选择级别和听力素材”；右侧只露出一枚半入柜的唱片边缘，不做卡片。
2. “听力计划”是首屏唯一羊皮纸主票据，展示真实 `planSummaryText`，右下角黄铜文字“设置计划”；`isYoyoFixedPlan` 时在票据下方插入窄书签“佑佑当前计划 / A1 · 阶段… / 查看”。
3. 级别不是胶囊组，改为目录柜上沿的七枚黄铜索引签；当前级别为墨蓝底加黄铜下划线，`C1/C2` 降低对比，点击仍沿用“暂未开放”。
4. 素材区为唱片书脊柜：每种素材是一条不同宽度的竖向书脊/磁带盒横切面，显示真实 `title`、`countText`、`stateText`。整行可点，不再附同权按钮。

### 状态

- 加载：`levelLoading && !materials.length` 时保留标题、计划票据和索引签；目录柜内出现 3 条无文字纸质书脊骨架，旁边保留真实文案“正在加载 {{selectedLevel}}”。
- 空：`materials.length===0 && !levelLoading` 时显示一个打开但无索引卡的木质抽屉，文案“该级别暂时没有听力素材”；这是表现补充，不改变业务判断与路由。
- 正常：真实类别按返回顺序排列；`同步中 / 待加入 / 已选 / 等待` 原样映射。`disabled` 书脊压低亮度且不响应。
- 完成/结果：该页无模块完成逻辑；只用 `已选` 苔藓绿书签表达计划结果，不伪造完成率。
- 错误：当前 JS 在无缓存的 `cloud-error` 下可能只撤掉加载；主题实现应在现有 `syncMode/syncDebug` 能力内给目录柜底部一条砖红边注“内容暂时没有同步成功，请稍后再试”，保留可用快照，不遮挡整个页面。

### 控件与交互

- 强动作：整张“听力计划”票据，文字动作“设置计划”。
- 次级动作：级别索引签、固定计划书签、素材整行点击。
- 切换级别时索引签先响应，再用快照/乐观素材保持目录稳定；新数据到达只替换书脊文字，不闪白屏。

## 5. `pages/level-stage/index`：章节索引册

### 首屏结构

1. 顶部不是入口页的目录柜，而是一张从档案盒抽出的墨蓝章节封套：`{{stage.levelId}} · {{stage.stageText}}`、`{{stage.title}}`、`{{stage.hint}}`；右上角为压印唱片编号，不使用轨道圆环。
2. `预计总时长 / {{totalMinutesText}}` 排成封套书脊上的黄铜借阅章，不独立做统计卡。
3. `taskGroups` 是一本纵向装订的曲目索引册。每组用不同纸色索引页隔开，组头展示 `categoryLabel / taskCountText / title / textType / minutesText / stateText`；点击组头展开或收起。
4. 展开后的 `tasks` 是唱片内页曲目表，以 `orderText` 做章节号，显示 `title / meta / stateText`。只有当前未完成且可用的任务行使用黄铜唱针形指示，整行是开始动作；完成行加苔藓绿“完成”压印。

### 状态

- 加载：`hydrated=false` 且无快照时显示合上的章节封套，三条索引页从侧边露出，不显示虚构任务名。
- 空：`hydrated && !hasTaskGroups` 沿用“暂时没有组合 / 后续会加入新的 A1 听力材料。”，放在空档案夹内；`round-3` 也按真实 `shouldShowTaskGroups` 结果进入此态。
- 正常：组默认展开，点击组头切换 `expanded`；页面可同时展开多个组，不能将 `expandedGroupKey` 误做单选手风琴。
- 完成：组内单条 `completedToday` 显示完成压印并保持可回看；组头 `stateText=完成` 时只做状态确认，不移除任务。
- 错误：有快照时继续显示快照，在封套底边加“正在使用最近内容”的低调边注；无快照且请求失败时显示砖红细边的档案夹和“内容暂时没有同步成功，请稍后再试”，不伪装为空。

### 控件与交互

- 强动作：第一个可开始任务的整行点击，不额外增加“开始”按钮外形；`stateText` 仅为右侧文字。
- 次级动作：组头展开/收起。禁用组保持 `disabled` 语义和无点击反馈。
- 进入课程前继续写入真实 `lessonTaskSnapshotV1`；主题不改变 fast、snapshotId、preview 查询参数。

## 6. `pages/lesson/index`：桌面唱机

### 首屏结构

1. 顶部为窄纸质唱片封套：真实 `coverBadge/categoryLabel`、标题、`训练中/完成/试听中`、预览或家长说明及 `displaySubtitle/coverMeta`。不再使用大面积产品 Hero。
2. 播放器占首屏主视觉：胡桃木唱机底座、墨蓝唱片、黄铜唱针。三遍 `passSteps` 做唱片外圈的 3 段刻纹，当前段为黄铜、完成段为苔藓绿；仍显示数字 1/2/3，保证进度可读。
3. 中央播放/暂停是全页唯一强动作；`正在播放/已暂停/等待播放`、`currentTimeLabel / durationLabel` 和进度轨在唱片下方纸带上。
4. “5 秒”和“×1.0”做唱机下沿两个小型机械拨键，不与播放同权。`task.isPendingAsset` 时唱针停在唱片外并不显示可播放控件。
5. 次屏内容不延续播放器卡形：文本学习使用索引卡抽屉；同步文本使用连续纸带；口语回答使用黄铜麦克风台。三者视觉结构彼此不同。

### 播放与任务状态

- 加载：优先渲染任务快照封套；`audioResolving` 时唱针停在唱片边缘，播放键显示低对比旋转刻纹，文案“等待播放”。不能用全屏加载挡住标题。
- 正常：播放时唱片低速旋转、唱针落下；暂停时保留角度。动效必须由 `isPlaying` 驱动并支持减少动态效果，不影响时间更新和 seek。
- 音频错误：`audioErrorText` 作为唱机纸带上的砖红校验章，保留“5 秒/倍速”但置灰无效项；调试详情只在 `showCloudDebug` 时显示，不进入评审视觉主层。
- 三遍完成：`lessonCelebrateVisible` 使用黄铜唱针回位与“完成”压印，不复用圆环烟花；`completionCardVisible` 为居中借阅回执，沿用“Great job today! / 今天也认真完成了，真不错。 / 今天打卡完成”。回执不增加按钮，维持自动返回逻辑。
- 预览/家长：封套明确“预览模式 · 不计入打卡”或“家长模式 · 不计入打卡”，进度仍可演示，但不制造云端完成感。
- 整页错误：`syncMode==='cloud-error'` 且无 `task` 时，显示合上的课程档案盒，沿用“课程暂时不可用 / 学习内容暂时没有同步成功，请稍后再试。 / 请稍后再重试”，服务原因置于砖红边注。

### 文本学习与同步文本

- `lessonStudyPack` 未生成：索引抽屉只显示“文本学习 / 听完后可选择生成学习包。”，次级动作“生成”。生成中保持抽屉尺寸，按钮显示加载。
- 已生成：抽屉顶部为三枚直角索引签“生词 / 短语 / 句型”；卡片改为连续索引条，保留真实释义、例句、发音、查词、加入词库。每条最多一个强调动作，“加入/已加入”为黄铜或苔藓绿小字章，“查词”为无底色文字。
- 学习包错误：沿用 `lessonStudyError`，在抽屉底部使用砖红校样线；不得自动重试生成。
- 同步文本：上一句、当前句、下一句排在窄幅连续纸带上，当前词以黄铜底线标记；点击可用行沿用 seek。盲听态显示“这一遍先盲听”；按需态显示“需要时再查看文本”；失败与空态沿用“文本加载失败，可稍后再试 / 暂无文本”。
- 查词弹层：像从桌边拉出的纸质词典抽屉，保留发音、释义、加入词库、加载和暂无释义状态；唯一强调动作“加入词库”。

### 口语分支与授权

- `passQuestionVisible`：问题印在一张窄问题签上，唯一强调动作“开始回答”。
- `speakingPanelVisible`：麦克风台展示“跟读评分/回答评分”、当前句、录音状态、分项分数和真实尝试记录；“开始录音/停止录音”是该状态唯一强动作，其余“满意，继续/完成跟读/播放录音/重新评分/播放建议”按当前流程出现为次级纸签。
- 录音错误和评分错误使用低饱和砖红批注；调试链路仅在真实 `speakingDebugLines` 存在时展示，修复确认后按项目规则撤除。
- `recorderPrivacyVisible`：深墨蓝遮罩上的纸质授权信笺，沿用“需要录音授权”及现有说明；“同意并开始”为唯一强动作，“稍后/查看指引”为文本动作。

## 7. 与雾蓝玻璃的结构差异

| 页面 | 雾蓝玻璃现状 | 图书馆静谧 |
| --- | --- | --- |
| 音频入口 | 渐变背景、玻璃计划卡、胶囊级别、统一横行 | 胡桃木目录台、羊皮纸计划票据、黄铜索引签、唱片书脊柜 |
| 听力组合 | Hero + 独立总时长卡 + 圆形轨道组卡 | 一体章节封套、书脊借阅章、装订索引册与曲目内页 |
| 课程详情 | 雾蓝玻璃卡、波形、珊瑚圆形播放键 | 桌面唱机、唱片三段刻纹、黄铜唱针、机械拨键 |
| 同步文本 | 三块玻璃字幕卡 | 连续纸带的前句/当前句/后句 |
| 学习包 | 同款圆角卡片堆叠 | 索引抽屉 + 直角分类签 + 连续索引条 |
| 完成反馈 | 圆环与悬浮完成卡 | 唱针回位、完成压印、借阅回执 |

## 8. 实施注意点

- 只新增 `theme-library` / `pageSkin` 呈现分支和主题 token；复用现有请求、快照、状态计算、音频上下文、进度提交和路由函数。
- `wx:if` 条件及状态优先级必须保持：有 `task` 显示课程；无 task 且 `cloud-error` 显示整页错误。快照先渲染、音频预取和次级内容延后加载不能被主题阻断。
- 不用真实图片作为必须资源；木纹、纸张可用极轻量位图或 CSS 纹理，但需确认包体与低端机性能。视觉板仅在 `docs`，不进入上传包。
- 所有圆角不超过 `16rpx`（约 8px）；底部导航仍使用全局图书馆墨蓝书脊条，尺寸与雾蓝主题一致。
- 触控热区不小于 `88rpx`；曲目标题保持单行省略，文本学习内容允许自然换行；320px 宽设备不得出现按钮或标签溢出。
- 图标实施时优先项目现有图标体系；唱针、唱片刻纹、索引签可用 CSS 基础形状，不使用 emoji 或手绘粗 SVG。
- 动效仅包含唱片旋转、唱针落下、抽屉展开和完成压印，单次过渡 `160–240ms`；播放旋转可持续，但页面隐藏、暂停或减少动态效果时必须停止。
- 实施 UI 改动时需另按项目规则追加 `docs/UI_DESIGN_LANGUAGE_LOG.md`；本次因唯一写入范围限制不修改该文件。

## 9. 视觉板覆盖

`audio-board.png` 为高保真评审板，覆盖：音频入口正常/加载/空、组合页正常展开/完成/空、课程播放/文本/完成/音频错误/整页错误及录音授权。板中数量和曲名仅作布局占位，文案优先取自当前 WXML/JS。
