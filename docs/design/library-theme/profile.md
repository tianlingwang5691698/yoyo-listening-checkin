# 我的模块：图书馆静谧主题逐页设计规范

## 1. 设计边界

- 主题：`themeId=library`，显示名“图书馆静谧”；默认主题 `warm / 雾蓝玻璃` 不变。
- 覆盖页面：`pages/profile/index`、`pages/identity/index`、`pages/family/index`、`pages/parent/index`、`pages/parent/detail/index`、`pages/admin/index`。
- 页面皮肤：`library-profile-bookplate`、`library-identity-reader-card`、`library-family-dossier`、`library-parent-letter`、`library-parent-dossier`、`library-admin-ledger`。
- 只重排现有字段、状态和动作，不新增主题切换入口，不虚构删除、导出、消息、权限审批、排行榜或数据分析功能。
- 视觉板：`docs/design/library-theme/profile-board.png`。板内数字和姓名仅为布局占位，实施时必须绑定真实字段。

## 2. 真实信息结构

| 页面 | 真实主数据 | 真实主动作 |
| --- | --- | --- |
| 我的 | `child`、`currentMember`、`syncMode`、`adminVisible`、`dailyEncouragement` | 保存昵称；进入日报、家庭与账号、管理 |
| 绑定身份 | `role`、`child.childLoginCode`、`childCode`、`displayName` | 家长绑定孩子记录 |
| 家庭 | `currentMember`、`child`、`studentCards`、`memberCards`、`bindingProfileRequired` | 切换身份、登录/绑定学生、选择学生、保存绑定信息 |
| 日报首页 | `child`、`todayReport`、`moduleStats`、`studentLinks`、`recentReports` | 查看学习档案、切换学生、展开最近 7 天 |
| 日报详情 | `report.items`、`speakingAttempts`、`completionItems` | 播放录音、打开当天内容案卷、展开原题和分析 |
| 管理 | `activeRows`、`inactiveRows`、`visibleRows`、`errorText` | 切换活跃/不活跃、展开用户 |

## 3. 模块母题

- **藏书票**：用于“我的”首屏。头像不是圆形气泡，而是 `EX LIBRIS` 书票，承载昵称、学号和每日鼓励。
- **读者证**：用于学号、学生登录、家长绑定。6 位学号像图书馆借书证编号，不能做后台 ID 样式。
- **会员档案夹**：用于家庭页身份、成员和绑定信息。资料以档案袋、抽屉签和印章区分层级。
- **家庭借阅关系**：用于家长绑定多个学生和切换学生。学生是可切换的“借阅关系卡”，当前对象盖“当前使用”印章。
- **日报信笺**：用于家长日报首页与详情。今日结论像一封给家长的信，明细像当天案卷，不做控制台。
- **账号印章**：完成、当前、已接通、待同步、错误、危险操作都用印章或校样边注表达。

## 5. `pages/profile/index`：我的藏书票

### 首屏

1. 顶部为深墨蓝短导航，下接一张横向藏书票，不再使用雾蓝圆环头像。
2. 藏书票左侧是书票头像与“学/家”小章；右侧显示 `child.nickname || '同学'`、学生态学号、`dailyEncouragement.english/chinese`。
3. 昵称编辑做成书票背面的签名栏：`昵称（必填）`、输入框、保存按钮。必填提示为砖红校样字，不铺红底。
4. 账号入口不是同款卡片列表：`日报` 是信笺入口，`家庭与账号` 是档案夹入口，`管理` 是台账入口；三者图案不同。

### 身份差异

- 学生：显示读者证编号 `childCodeText`；入口副文案为“学生 · 已接通/待同步”。
- 家长：不显示学生自己的学号卡；“家庭与账号”副文案为“家长 · 已接通/待同步”；可见“管理”时使用窄台账入口。
- 管理员：只新增管理入口的可见性，不在我的页展示后台数据。

### 状态

- 加载：`profileHydrated=false` 时保留藏书票外框和三条纸纹骨架，不显示空昵称或“未绑定”。
- 快照首显：命中 `profileHomeSnapshotV1` 时直接显示真实昵称和入口，右上小黄铜点表示后台刷新。
- 无数据：无可展示昵称时显示签名栏为主，提示“请设置昵称”，不展示完整空档案。
- 正常：昵称、学号、入口可用；整行入口点击，不额外放同权重按钮。
- 错误：云端刷新失败但有快照时保持旧档案；无快照时在藏书票下方显示“档案暂时无法同步”，保留昵称保存区。
- 调试：`syncDebug.show` 只作为折叠边注出现，遵循线上调试规则修复后撤掉。

## 6. `pages/identity/index`：读者证绑定

### 结构

- 页面标题“绑定身份”保留，视觉改为两张图书馆索引签：`我是家长`、`我是学生`。
- 家长态是一张“代学生绑定”的读者证申请表：6 位学号为大号编号格，关系输入为档案落款。
- 学生态是一张可递给家长的读者证：显示 `child.childLoginCode || '未生成'`，不提供绑定按钮。

### 状态

- 加载：现有页面没有显式 `loading` 字段；进入时表单先展示稳定纸面，学号处显示“待同步”骨架。
- 绑定输入：`childCode` 限 6 位数字；关系文案使用现有“妈妈 / 爸爸 / 老师”示例。
- 成功：沿用 toast“已加入孩子记录”，证件盖苔藓绿“已验证”短暂反馈。
- 错误：`请输入 6 位学号`、`绑定失败` 原位显示在学号格下方；不弹新的说明卡。
- 空：学生学号未生成时显示“未生成”，不得生成假编号。

## 7. `pages/family/index`：家庭档案夹

### 首屏

1. 顶部为“家庭与账号”档案夹封面，显示 `syncMode` 印章。
2. `bindingProfileRequired=true` 时优先展示“补齐绑定信息”档案页，两个输入字段和唯一主动作“保存”。
3. 非补齐态展示账号身份页签：`studyRoleLabel`、切换按钮、学生态学号。
4. 家长态的绑定学生区是“家庭借阅关系”：每个学生是横向借阅卡，当前学生盖“当前”印章。
5. 登录/绑定区使用读者证编号格：学生态标题“登录其他学生账号”，主动作“登录”；家长态标题“绑定学生”，主动作“绑定”，下方才是关系输入。
6. 成员区是档案夹底部成员索引，`本机` 是小印章，不做头像云图。

### 身份与切换

- 学生态：显示本机学号；允许登录其他学生账号；切回学生后仍按真实逻辑 `wx.switchTab('/pages/home/index')`。
- 家长态：显示绑定学生、绑定表单、成员；选择学生只改变查看目标，不改变本机学生账号。
- 切换身份：按钮是次级档案签，不与登录/绑定主动作同权重。

### 危险操作

- `undoLastListened`：放入档案夹背面“修正今日记录”，砖红校样边注，按钮文案“撤回”。确认弹窗沿用“清掉多记播放？”。
- `leaveFamily`：放入独立“解除绑定”信封，按钮文案“退出”。确认弹窗沿用“退出孩子记录？”。
- 危险区不出现在首屏主路径上；只使用低饱和砖红，不用大面积警告色。

### 状态

- 加载：保留档案夹封面和身份条骨架；绑定学生区显示三张窄纸签骨架。
- 无绑定学生：家长态没有 `studentCards` 时不显示空大卡；直接把“绑定学生”读者证表单作为主内容。
- 正常：学生卡整行可点；当前状态只用印章，不增加按钮。
- 成功：保存、绑定、登录、切换沿用现有 toast；页面刷新后印章变化。
- 错误：保存/绑定/登录/切换失败原位显示砖红边注并保留输入值。
- 调试：`syncDebug` 位于封面底部可复制边注，正式态隐藏。

## 8. `pages/parent/index`：日报信笺首页

### 首屏

1. 顶部为日报信笺抬头：`日报`、`child.nickname`、`child.childLoginCode`、日期。
2. 多学生家长显示 `picker` 为“切换学生”窄书签，不能做主按钮。
3. 今日结论是一封短信：`parentSummary.title/copy/detail`，主动作只有“查看学习档案”。
4. 学习画像不做六张同款指标卡：听力像声纹小票，阅读像页码签，语法像校样签，写作像稿纸签，词汇像索引卡，口语像录音回执。
5. 最近 7 天是横向借阅日期章，点击 `查看` 才展开。

### 状态

- 加载：先读 `parentDashboardSnapshotV3`；无快照时信笺头可见，今日结论区显示纸纹骨架。
- 无记录：使用现有 `parentSummary` 文案“今天还没有完成记录”，不新增学习建议。
- 正常：展示今日摘要和模块数据；`查看学习档案` 进入当天详情。
- 多学生切换：清空旧 `moduleStats/recentReports` 后显示当前目标的信笺骨架，避免旧孩子数据闪现。
- 最近 7 天加载：`recentLoading` 时只让“查看”变为“加载中”，不遮挡日报首页。
- 错误：首屏云端失败且有快照时保留快照；无快照时在信笺脚注显示“日报暂时无法同步”，可保留重试触点。

## 9. `pages/parent/detail/index`：当天内容案卷

### 首屏

- 顶部是“家庭观察日报”信封，保留 `report.dateLabel`、`completedCount`、`totalCount`、`totalMinutes`，但指标做成三枚小印章，不做仪表盘。
- 学习节奏是纵向借阅时间线：`report.items` 每项显示标题、完成状态、进度条和 `timeLines`。
- 内容档案首层只列出当天有记录的听力、口语、词汇、阅读、语法和写作模块。
- 声音档案并入口语模块，点击后再显示平均分、最近得分、录音条目和播放按钮。

### 展开态

- `activeArchiveModule` 只允许同时展开一个模块；非口语模块通过 `loadArchiveModule` 按类型读取当天记录。
- 阅读、语法、写作、词汇和听力学习包使用对应纸件形态：
  - 阅读：原文页 + 题号索引签 + 答案句。
  - 语法：校样题纸 + 选项 + 孩子选择 + 分析。
  - 写作：作文题目、学生作文、内容/结构/语言/问题/建议、参考范文。
  - 词汇：背诵显示复习/不熟数量；听写显示正确/总数和错词数。
  - 听力学习包：不在本页伪展开，沿用真实跳转到 `lesson` 聚焦学习包。

### 状态

- 加载：日报信封先显示日期；节奏、声音、案卷三个区各自纸纹骨架。
- 空：`report.items.length=0` 显示“这一天还没有记录。”；无录音显示“这一天还没有录音。”；无内容显示“这一天还没有学习内容记录。”。
- 播放：`loadingAttemptKey` 为黄铜唱针移动；播放中按钮为墨蓝，暂停保持同一尺寸。
- 详情加载：单条 `detailLoading` 在该案卷内显示“加载详情中”，不锁全页。
- 错误：日报加载失败保留已有内容；内容案卷失败沿用 toast“记录加载失败”，案卷保持合上状态。
- 录音错误：沿用“录音暂不可播放 / 录音加载失败 / 录音播放失败”，原位砖红边注，不清空列表。

## 10. `pages/admin/index`：管理员台账

### 结构

- 顶部“后台”改为“管理档案”台账页眉，保留“默认显示多次登录的活跃用户”和 `activeTotal`。
- `active / inactive` 切换做成台账页签，不做胶囊统计栏。
- 用户行像登记簿：姓名、活跃文本、角色、家长数、展开。
- 展开只显示真实 `ID` 和 `家长`；不提供复制、删除、解绑、编辑。

### 状态

- 加载：台账封面和 4 行登记簿骨架，文案“加载中”可作为小章。
- 无权限/错误：`errorText` 显示为砖红审核条，标题沿用“后台暂时不可用”，唯一动作“重试”。
- 空：`!visibleRows.length` 显示“暂无用户”，用合上的登记簿图案。
- 正常：活跃/不活跃列表切换只替换登记行；展开不改变行外布局。
- 管理身份：仅管理员可见；非管理员看到错误态，不出现任何后台操作入口。

## 11. 跨页状态矩阵

| 状态 | 统一处理 |
| --- | --- |
| 学生身份 | 读者证、学号、登录其他学生账号；训练数据仍只在学生模式写入。 |
| 家长身份 | 家庭借阅关系、绑定学生、查看日报；家长练习/试听不写入学生记录。 |
| 管理身份 | 仅查看台账和展开详情，不新增修改能力。 |
| 绑定 | 统一用 6 位读者证编号格；家长绑定需关系，学生登录只输学号。 |
| 切换 | 身份切换是次级档案签；绑定学生切换是借阅关系卡当前印章。 |
| 无数据 | 用合上的档案/空信笺，不补造推荐、统计或进度。 |
| 加载 | 保留页面骨架和已知快照，局部刷新不遮挡整页。 |
| 错误 | 砖红校样边注 + 现有重试/保留输入；不只依赖 toast。 |
| 危险操作 | 独立背面档案区 + 二次确认；不与主动作同屏抢焦点。 |

## 12. 与雾蓝玻璃的结构差异

| 当前雾蓝结构 | 图书馆静谧结构 |
| --- | --- |
| 圆环头像、玻璃 Hero | 藏书票、读者证、档案封面 |
| 日报/家庭/管理同类行卡 | 信笺入口、档案夹入口、台账入口三种形态 |
| 家庭成员像节点/卡片 | 家庭借阅关系卡 + 成员索引 |
| 日报画像接近指标网格 | 模块档案小票，强调今日结论 |
| 日报详情多块同款卡 | 学习节奏时间线、声音回执、内容案卷 |
| 后台列表 | 管理登记簿 |

## 13. 实施注意点

1. 只新增 `theme-library` 视觉分支；复用现有 `store.getProfileData/getFamilyPageData/getParentDashboard/getDailyReportByDate/getAdminFamilyList`。
2. 快照优先规则不变：我的页、日报首页命中快照先展示；目标学生变化时不得沿用旧目标快照。
3. 所有按钮保留真实事件：`saveChildProfile`、`joinFamilyByChildCode`、`toggleStudyRole`、`selectStudent`、`undoLastListened`、`leaveFamily`、`openDailyDetail`、`loadArchiveModule`、`toggleCompletionDetail`、`switchListMode`。
4. 错误和调试信息遵循 `docs/ONLINE_DEBUG_DB_RULES.md`：测试阶段可显示链路点，修复确认后撤掉。
5. 视觉板仅供评审，不进入小程序上传包。
