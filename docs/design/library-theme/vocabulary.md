# 图书馆静谧主题：词汇模块设计规范

## 1. 范围与真实业务

- 主题：`themeId=library`，显示名“图书馆静谧”；`warm / 雾蓝玻璃` 保持默认。
- 页面：`pages/reading/flashcards/index`，注册标题“词汇复习”，自定义导航显示“词汇”。
- 入口：`pages/home/index.js` 路由至 `/pages/reading/flashcards/index`；页内返回顺序为复习 -> 当前词库 -> 书库 -> 上一页。
- 页面状态轴：`sourceMode=bookshelf/library`；`mode=library/review`；完成由 `reviewCompleted` 表达。
- 真实词库：我的词库、初中英语词汇 乱序、高中英语词汇 乱序。我的词库汇集各模块已加入的生词、短语、句型。
- 真实学习规则：按 `REVIEW_DAYS=[0,1,2,4,7,15,30]` 复习；默认今日新学 10、今日复习 20；每次以 5 为步长调整。
- 不新增路由、字段、筛选、统计、任务或示例数据。视觉板中的单词仅为现有演示词卡的布局占位，不进入代码。

## 2. 主题叙事与布局原则

词汇模块是一组可取用的私人索引系统：书库是立式书脊墙，词库是平铺索引抽屉，学习是桌面单张抽认签，完成是归档签。四个场景共享胡桃木、羊皮纸、墨蓝与黄铜，但不复用同一张卡片模板。

- 模块图案：书脊词库、索引卡、抽认签、记忆抽屉；禁止通用圆环、emoji 和持续漂浮动画。
- 圆角：纸张 `4px`，木质面板 `6px`，按钮 `6px`；不用胶囊主按钮。
- 每页一个强动作：书库为整行进入；词库为“开始背诵”；复习判断阶段为“我认识”；揭示阶段为“下一个”；完成为“返回词库”。
- 音频“听”、返回、书库、调整计划、查看词库、取消/确定均为轻动作，不与主动作同权重。
- 页面数据、缓存优先、云端刷新、学习记录与音频逻辑完全复用现有实现。

## 3. 页面一：词汇书库

### 首屏结构

1. 融合式顶部导航：胡桃木上沿中的返回刻线、居中“词汇”，不使用悬浮玻璃条。
2. 书库铭牌：左侧“我的词汇书库 / 选择词库，继续今天的背诵”，右侧三本高低不同的实体书脊与一张斜插索引签。
3. 立式书脊墙：三本真实词库按现有顺序陈列。每本以不同书脊宽度、布纹和黄铜压印区分，整本可点；标题横向排在相邻目录签上，已有进度显示“`n` 个有进度”。

### 控件与交互

- “我的词库”书脊压印“库”，副文案“阅读、语法和已加入的生词”。
- 初中、高中词书分别压印“初”“高”；保留“词卡组 / 记忆栈”来源语义，但作为小号书脊馆藏章。
- 整行/整本点击进入，不另放同权重按钮；右缘仅显示细黄铜书签箭头作为可点击提示。
- 导入中仅锁定当前书脊，其他书脊保持稳定且不可重复触发当前导入。

### 状态

| 状态 | 呈现 |
| --- | --- |
| 加载 | 保留三层书架与标题；书脊标签使用短纸纹占位，不显示转圈或空白页。 |
| 空 | 书库本身不为空，默认三本真实入口继续可见；词库内容为空只在进入后表达。 |
| 正常 | 书脊、真实标题、已有进度与来源章完整显示。 |
| 完成 | 返回书库时在刚学习的书脊上增加低调黄铜归档线，不新增完成按钮或统计。 |
| 错误 | 当前词书目录签显示低饱和砖红细边与“词书读取失败”；测试期其下保留现有可复制 `flashcardDebugLines`，不得用错误覆盖其他词库。 |

### 独有图案

竖向书脊压印、木架横梁、馆藏编号短线。书架是页面骨架，不做列表卡片。

## 4. 页面二：词库与计划

### 首屏结构

1. 当前词库抽屉铭牌：`activeSourceTitle`、可选“演示”标记、`已学 n / total · 打卡 n 天`、音标预览；右上“书库”为轻返回签。
2. 黄铜抽屉刻度：用一条直线表达 `learnedPercent`，刻度下依次写“新词 / 复习中 / 掌握”及真实数量，不使用三张统计卡。
3. 唯一强动作“开始背诵”：整宽墨水蓝台面按钮，黄铜细边，位于进度后。
4. 次级抽屉把手：“调整计划”“查看词库/收起词库”。展开内容从主面板下方抽出，不覆盖强动作。

### 展开区

- 调整计划：同一张双栏账页展示“今日新学”“今日复习”；`- / 数值 / +` 为黄铜机械步进器，长按规则保持现有逻辑。
- 数值选择：底部羊皮纸抽屉，标题为真实 `limitPickerTitle`，保留“取消 / 确定”，滚轮当前值用墨蓝横线夹住。
- 最近记录：按真实 `logs` 显示词条与“认识 / 不熟”，做成日期借阅条，不扩展不存在的时间或成绩。
- 查看词库：按“生词 / 短语 / 句型”分成三个索引隔板。条目是无外卡边框的纸张行：词或短语、音标、释义、例句；例句仅在真实存在时显示。

### 状态

| 状态 | 呈现 |
| --- | --- |
| 加载 | 有缓存先显示缓存；无缓存时固定铭牌与抽屉轮廓，正文为三条纸纹骨架；`importingBook` 对应“正在建立计划。”语义。 |
| 空 | 铭牌数字归零；索引抽屉显示“暂无词汇。”，保留“书库”轻入口；“开始背诵”降为不可用墨线，不造推荐词。 |
| 正常 | 展示真实进度、打卡天数、计划与分组内容；默认收起计划和词库，首屏聚焦开始背诵。 |
| 完成 | 从完成页返回后进度刻度与打卡天数刷新；不再出现第二张庆祝卡。 |
| 错误 | 云端刷新失败但有缓存时保持可学，并在抽屉底部显示砖红边注；无缓存时显示“词书读取失败”。测试期保留具体链路 debug，确认修复后撤掉。 |

### 独有图案

记忆抽屉、字母索引签、黄铜百分比刻尺、纸边压痕。该页是“抽屉 + 索引”，不是书架列表。

## 5. 页面三：学习与复习

### 首屏结构

1. 极简进度梁：左侧“词库”退出签，中间 `当前 / 本轮总数`，以黄铜书签沿直线移动；不展示后台式三项指标面板。
2. 桌面抽认签：单张大羊皮纸占据视觉中心，左上角小索引签显示“生词 / 短语 / 句型”；中央显示 `displayText`，下方显示可用音标。
3. 发音控件：仅 `canSpeak` 时出现细线扬声器/“听”轻按钮；加载时黄铜刻线呼吸一次，不改变尺寸。
4. 稳定操作槽：未揭示时底部为“不认识 / 我认识”；揭示后同一位置保留“下一个”为唯一强动作，按钮高度和卡片分区不跳动。

### 判断与揭示交互

- 点“不认识”或“我认识”只翻开下半张答案纸，不左右滑卡。
- 揭示区依次显示真实释义、英文例句、中文翻译；缺字段时按现有规则显示“暂无释义”或省略例句区。
- “标记为太简单 / 撤销”是答案纸右上角的铅笔边注，不做第三个主按钮。
- `audioLoading || audioPlaying` 时“下一个”禁用但位置不变；高频按压仅轻微下沉回弹。
- 不认识的词回到本轮队尾；认识/太简单按现有记忆状态推进。

### 状态

| 状态 | 呈现 |
| --- | --- |
| 加载 | 保留进度梁和完整抽认签尺寸；词面为一条墨色纸纹，操作槽禁用，避免布局跳动。 |
| 空 | 无到期词时在桌面中央放合拢索引盒，文案“今天没有复习。”；轻入口“词库”，无虚构任务。 |
| 正常 | 未揭示只显示词面、音标、听音和两个判断；揭示后显示释义与例句，并以“下一个”推进。 |
| 完成 | 转入独立归档完成状态，当前抽认签退出，不在原卡上叠弹窗。 |
| 错误 | 发音失败用现有“发音失败，稍后重试”轻提示；同步失败不阻断本轮本地推进，测试期在离开复习后于词库边注链路位置。 |

### 独有图案

单张抽认签、桌面压纸角、黄铜进度书签、答案翻页折线。学习页不是列表，也不复制词库抽屉。

## 6. 页面四：完成归档

### 首屏结构

1. 胡桃木桌面中央放一只关闭的记忆抽屉，三张已归档索引签露出黄铜边。
2. 抽屉馆藏章写“完成”，标题使用真实文案“今天词汇完成啦”。
3. 唯一强动作“返回词库”，墨水蓝实底、黄铜细边；不增加分享、再来一轮、成绩或虚构奖励。

### 状态

- 进入：最后一张词卡沿短路径滑入抽屉，馆藏章压下；完成音效沿用现有资源。动效一次完成，不循环。
- 正常完成：只显示完成章、真实标题和返回词库。
- 写回中/失败：完成画面不回退；记录写回按现有队列继续，测试期回到词库后显示链路边注，不制造失败完成页。

### 独有图案

归档抽屉、馆藏压印、三层索引签。完成页是静态归档场景，不使用圆形奖章或彩屑。

## 8. 与雾蓝玻璃的结构差异

| 场景 | 雾蓝玻璃现状 | 图书馆静谧 |
| --- | --- | --- |
| 导航 | 半透明雾蓝固定玻璃条 | 与胡桃木书架/桌面融合的刻线导航 |
| 书库 | 圆角玻璃列表卡 + 小封面 | 立式实体书脊墙，整本进入 |
| 词库 | 玻璃 hero、胶囊标签、进度条、卡片列表 | 抽屉铭牌、黄铜刻尺、索引隔板与无框纸行 |
| 计划 | 两张玻璃统计/设置块 | 一张可抽出的双栏账页与机械步进器 |
| 学习 | 叠层玻璃卡、圆形听音、胶囊按钮 | 单张羊皮抽认签、桌面压角、矩形稳定操作槽 |
| 完成 | 叠卡 + 圆形完成徽章 | 关闭的记忆抽屉 + 馆藏压印 |

差异只发生在呈现结构、材质和动效；所有数据、路由、点击结果、缓存与云端同步保持一致。

## 9. 实施注意点

- 建议使用 `theme-library` + `pageSkin=vocabulary` 分支与 CSS 变量实现；不得复制 `loadCards`、复习队列、音频或提交逻辑。
- `library` 主题完成验收前不恢复“我的”页主题切换入口；默认仍为 `warm`。
- 首屏优先缓存；无缓存加载骨架必须与最终结构同尺寸。`loading` 当前未在 WXML 独立渲染，实施时只增加呈现分支。
- `library` 数据目前为实例字段以控制渲染体积；展开词库时才生成 `libraryGroups`，不得改成首屏渲染全量词书。
- 书脊、按钮、进度与操作槽必须有稳定尺寸；短语、句型按现有类型动态字号，最长词不挤压听音或底部动作。
- 保留真实空文案：“暂无词汇。”“正在建立计划。”“今天没有复习。”；保留真实错误文案：“词书读取失败”“播放失败，稍后再试”“发音失败，稍后重试”。
- 测试阶段错误必须在页面写明 `reading/flashcards -> store -> cloud/storage` 链路位置；修复确认后撤掉调试信息。
- 视觉板仅供评审，`vocabulary-board.png` 不进入小程序上传包。

## 10. 视觉板覆盖

高保真视觉板按 2 x 3 手机屏组织：词汇书库正常态、当前词库正常态、调整计划展开态、学习未揭示态、学习揭示态、完成归档态；在书库与词库屏中嵌入加载/空/错误小样，确保主要页面与状态完整可评审。
