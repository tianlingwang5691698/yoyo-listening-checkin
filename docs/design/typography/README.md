# 题干与解析 UI 字体层级总规范

## 1. 适用范围

本规范覆盖小程序内所有题目学习界面：

- [阅读与听力](./reading-listening.md)
- [语法](./grammar.md)
- [写作与翻译](./writing-translation.md)
- [口语](./speaking.md)

主题设计文档负责材质、颜色和场景表达；本规范负责题干、答案、解析、证据和评分信息的语义层级。两者冲突时，字体语义和可读性以本规范为准。

## 2. 字体角色

| 角色 | 字体 |
| --- | --- |
| 中文题干、中文解析、控件 | `var(--font-body-family)` |
| 英文文章、答案原句、写作原文 | `var(--font-english-serif-family)` |
| 英文口语题干、短指令 | `var(--font-english-sans-family)` |
| 解析标题 | 暖色/龙珠用 `var(--font-body-family)`；图书馆/航海可用 `var(--font-title-family)` |
| 分数、题号、答案字母、状态数字 | `var(--font-number-family)` |

不得新增模块私有字体栈替代上述角色。所有题目与解析文字 `letter-spacing: 0`，不得使用负字距。

## 3. 统一结果层级

四主题必须定义并使用同一组结果变量：

| 层级 | Token | 字号 | 行高 | 用途 |
| --- | --- | ---: | ---: | --- |
| 总分 | `--result-score-size` | `48rpx` | `1.08` | 总分、Band、核心结果数字 |
| 结果标题 | `--result-title-size` | `32rpx` | `1.3` | 批改结果、逐题解析、学习包 |
| 解析标题 | `--result-section-size` | `28rpx` | `1.4` | 考点、讲解标题、分项标题 |
| 解析正文 | `--result-body-size` | `26rpx` | `--result-line-body: 1.72` | 主解析、总结、建议 |
| 证据与补充 | `--result-support-size` | `23rpx` | `--result-line-support: 1.58` | 答案句、翻译、排除说明、修改理由 |
| 元信息 | `--result-meta-size` | `21rpx` | `1.25-1.35` | 状态、答案字母、题号、标签、次级动作 |

层级顺序固定为：

`总分 > 结果标题 > 解析标题 > 题干/解析正文 > 证据与补充 > 元信息`

同一区域不得把状态标签、辅助翻译或按钮做得比题干、解析正文更大。

## 4. 题干层级

| 题干类型 | 字号 | 行高 | 字重 |
| --- | ---: | ---: | ---: |
| 普通阅读/听力题干 | `26rpx` | `1.6-1.72` | `400-500` |
| 语法单题题干 | `32rpx` | `1.65` | `500` |
| 写作任务正文 | `28rpx` | `1.72-1.78` | `400-500` |
| 口语核心题干 | `33-34rpx` | `1.5` | `600` |
| 选项正文 | `26rpx` | `1.55-1.65` | `400-500` |
| 题号、年份、地区、题组 | `21-22rpx` | `1.35-1.45` | `500-600` |

特殊放大只允许用于“当前唯一需要朗读或回答的核心题干”，不能把普通选择题统一放大到口语题干规格。

## 5. 结构与留白

- 题干、选项、答案反馈、解析按自然阅读顺序排列，不使用浮层覆盖题干。
- 解析在原题下方展开；优先使用留白、细分隔线或左侧证据线，不再嵌套同权重卡片。
- 解析标题与正文间距 `12-16rpx`；正文与证据间距 `14-18rpx`。
- 相邻题目间距不得靠字号撑开，使用稳定容器间距或分隔线。
- 长英文题干、长单词、公式和 URL 必须换行，不横向溢出。
- 320-430px 宽度下，题号、状态和答案标签不得挤压正文。

## 6. 四主题边界

四主题可以改变：

- 标题字体角色；
- 文字颜色、细分隔线、左侧证据线；
- 纸张、玻璃、航海日志、训练板材质。

四主题不得改变：

- 结果字号变量；
- 题干与解析的语义顺序；
- 正文、证据、元信息的大小关系；
- 题干和解析的可读行高；
- 用卡片嵌套替代层级。

## 7. 禁止项

- 用 `font-weight: 800/900` 强行制造普通题干层级。
- 解析正文小于 `23rpx`。
- 证据、翻译与元信息使用同一字号，导致层级消失。
- 用颜色同时承担正确性和信息层级；正确/错误色只表达状态。
- 大段中文解析使用衬线字体。
- 英文阅读正文使用控制台字体或等宽字体。
- 在同一解析区域出现三个以上同权重标题。
- 使用负字距、全大写 eyebrow 或夸张字间距。

## 8. 改动门禁

修改题干、选项、答案、解析、评分报告相关 WXML/WXSS 时必须：

1. 同步更新本目录对应模块规范和 `docs/UI_DESIGN_LANGUAGE_LOG.md`。
2. 四主题共同验证，禁止只修一个主题。
3. 运行 `node --test tests/result-typography-hierarchy.test.js tests/ui-typography-docs.test.js`。

涉及真实页面验收时，按项目规则仅使用 CLI + `miniprogram-automator` 单会话批量验证。
