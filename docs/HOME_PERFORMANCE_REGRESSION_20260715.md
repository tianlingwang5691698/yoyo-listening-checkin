# 首页性能整改与回归记录

## 硬性要求

- 缓存首屏 `pageReady <200ms`。
- 无缓存首屏目标 `<600ms`，硬上限 `<800ms`。
- 首页后台 `getDashboard(view=home) <1000ms`。
- 连续 3 轮任一轮 `>=1000ms`、`dataFresh!=true` 或出现 timeout，均判定不合格。
- 首页刷新完成前不得启动其他页面云预取。

## 首页必需数据

- 当前学生目标与昵称。
- 今日任务分组、完成状态和播放必需字段。
- Day、今日完成分钟、今日目标分钟。
- 学习入口和本地词汇摘要。

首页不读取完整用户资料、设备会话、统计大字段、完整历史记录或其他页面目录。

## 问题与整改

整改前：首页打开 `200–1600ms` 后并发预取阅读、词汇、语法、写作、音频概览、成长和个人页，与 dashboard 云刷新竞争资源。

第一轮：dashboard 完成后再错峰预取；首页隐藏或卸载时取消计时器。

第二轮：

- 使用 dashboard 快照中的 `familyId/childId` 作为目标。
- 云端并行校验目标成员与孩子。
- 首页不查询完整用户和设备会话。
- `dailyTaskProgress`、`dailyCheckins` 只投影首页计算字段。
- 保留有效计划、今日进度、打卡和当日日报，确保数据仍收敛到云端真实状态。

## 回归结果

- 整改前：`pageReady=26–62ms`；`cloudRefresh=1237–4476ms`；出现 1 次 timeout。
- 第一轮：`pageReady=20–28ms`；`cloudRefresh=1017–1470ms`；仍不满足 `<1000ms`。
- 底部 Tab 连续切换 10 次：路径正确，无异常。
- 第二轮本地测试：`79/79` 通过，JS 语法与 diff 检查通过。
- 最终线上性能：需部署 `yoyo` 云函数后连续复测 3 轮。
