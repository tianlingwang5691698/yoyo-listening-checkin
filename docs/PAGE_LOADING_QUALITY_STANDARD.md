# 页面加载质量标准

后续修改页面打开速度、加载逻辑、缓存策略时，先参考本文。

## 总原则

- 首屏先显示可用内容，不因云端刷新阻塞。
- 快照必须覆盖下一个页面“首个可操作动作”的全部字段；字段来自云端真实数据，不能靠前端临时猜。
- 页面加载顺序按用户操作顺序排：先让首个动作可用，再后台刷新或按需加载次级内容。
- 有缓存先用缓存，再后台刷新。
- 加载过程不弹 `showLoading`，不显示“加载中 / 准备中 / 同步中 / 生成中”等等待文案。
- 不先清空旧内容再请求新内容。
- 生成、批改、评分、上传等长任务只绑定在按钮局部状态，不影响整页浏览。
- 页面层只编排展示和交互；业务规则仍放在云函数 engine / service。

## 速度目标

- 常用页面缓存命中：首屏可见小于 `300ms`。
- 常用页面冷启动云端返回：首屏可见小于 `1200ms`。
- 重型页面：先显示已有摘要，详情数据延后加载。
- 模型生成类操作：不纳入首屏指标，只看按钮可用状态和失败重试。

## 首屏标准

- 首页：显示今日任务卡、学习入口、词汇摘要。
- 听力课程：显示课程标题、播放器骨架、当前任务状态。
- 阅读目录：显示目录层级或上次缓存目录。
- 阅读详情：显示文章和题目；学习包延后。
- 语法页：显示阶段和考点；题目详情按点击加载。
- 词汇页：显示书库或上次词库缓存。
- 记录页：显示核心统计和本月热力图；作文、追赶、近期明细延后。
- 家长页：显示日报摘要；完成详情按展开加载。

## 快照字段规则

- 跨页跳转前，上一页必须写入下一页首动作需要的最小快照；不能只写标题、状态和 ID。
- 快照字段必须和云端真实字段一致；涉及云存储的路径、fileID、URL 必须来自云端任务或记录。
- 快照只保留首动作字段和首屏展示字段；transcript、学习包、解析、评分记录、历史明细等大字段后台或按需加载。
- 若快照缺少首动作字段，下一页必须回源补完整数据，不能显示成可操作但实际不可用。
- 新增页面入口时，必须先定义“进入后用户第一个动作是什么”，再决定快照字段。

## 缓存规则

- `utils/store.js` 的读接口默认允许缓存。
- `getDashboard`、`getLevelOverview`、`getReadingHome`、`getReadingPassage`、`getGrammarHome`、`getProfileData`、`getParentDashboard` 必须优先缓存。
- `getMaterialIndex` 应改为默认缓存，后台刷新。
- 学习包读取先查本机缓存和通用读缓存；用户点击“生成/刷新”时才强制云端。
- 音频临时链接可做短期缓存，避免同一页面反复取 URL。
- 写接口成功后再清相关读缓存，不全量清空不相关缓存。

## 加载分层

1. 首屏必需数据：只放页面标题、主任务、核心入口。
2. 次级数据：记录明细、作文列表、家长完成详情、相邻月份热力图，延后请求。
3. 重型数据：学习包、批改、解析、评分、发音合成，只由用户动作触发。

## 空状态规则

- 请求中不显示空状态。
- 确认无数据后才显示“暂无内容 / 暂未开放 / 未绑定”。
- 不用“还在准备中 / 同步中 / 加载中”。
- 失败态要可操作：重试、返回、稍后再试。

## 页面级建议

### 首页

- 保持 `getDashboard` 缓存优先。
- 选择学生/家长身份后，先按目标学生读取首页 dashboard 快照显示今日任务，再后台刷新云端。
- 底部导航页（音频、成长/记录、我的）进入时必须先使用本页快照/缓存显示首屏，不允许等待云端后才显示主体内容。
- 音频 tab 首屏默认优先展示 A1 的真实素材字段/快照，再后台预取其他 level；切换 level 不允许清空当前列表或只显示加载中。
- 音频 tab 分级素材详情必须使用 `getListeningMaterialDetail` 缓存/快照首显；每条素材进入课程前必须已有云端真实 `audioUrl/audioCloudPath/audioFileId/audioSource` 字段之一。
- 我的页快照必须包含后台入口需要的云端权限字段，例如 `getAdminStatus.isAdmin`，不能把整页展示态当作云端字段写入。
- 词汇摘要只读本地，不阻塞云端。
- 查看记录时可先跳转，再在记录页加载明细。

### 听力课程页

- `getTaskDetail` 用缓存首显，后台刷新。
- 今日任务、今日完成、阶段页、记录页、家长日报进入听力课程，都必须先写入上一页已有的 `taskSnapshot`。
- `taskSnapshot` 必须保留云端返回的 `audioUrl`、`audioCloudPath`、`audioFileId`、`audioSource`，不能只存标题和完成状态。
- 新写入的听力快照播放字段必须来自云端任务字段，并和云存储真实路径一致；前端不能为新快照临时猜云路径。
- 播放器音频解析/预加载优先级最高；学习包、口语记录、问题区、完成明细只能后台加载。
- 已完成任务仍可点击查看并播放，不能因为完成状态禁用整行或阻断播放器。
- 音频 `getTempFileURL` 做短期缓存。
- 文本和学习包不进入首屏阻塞链路。
- `loadCachedLessonStudyPack` 先读本机缓存，不直接云端 cacheOnly。

### 阅读页

- 阅读目录使用 `getReadingHome` 缓存。
- 阅读详情使用 `getReadingPassage` 缓存。
- 学习包先读本机缓存；缺失时用户点击生成。
- 句子翻译、查词、发音均按点击触发。

### 语法页

- 一模、二模目录可并发加载。
- 点击具体考点时，题目和进度并发加载。
- 错题本不阻塞普通题库入口。

### 词汇页

- 词书优先读手机本地文件缓存。
- 大词书首次导入不要阻塞书库首屏。
- 词表、计划、闪卡三层数据分开更新。

### 记录页

- 首屏只等 `dashboard + 当前月 heatmap`。
- 当天详情、近 7 天、作文记录、追赶任务延后；记录页选中日期后只更新摘要和选中态，点“查看”才加载当天任务明细。
- 相邻月份预加载只在首屏稳定后执行。

### 家长页

- 日报摘要先显示。
- 日报模块分析必须先用摘要快照显示；云端 `summaryOnly` 只能取摘要字段，不能运行完整 dashboard、详情 hydration 或串行 7 天重链路。
- 我的-日报首屏只拿今日和最近 7 天摘要；今日详情、最近 7 天任一天详情必须点击“查看”后再加载。
- `completionItems` 可后台合并。
- 详情 hydration 只在展开时执行。

### 材料和写作页

- `getMaterialIndex` 必须支持缓存。
- 听力入口必须先读 `getMaterialIndex` 缓存/快照；云端慢或错误时不能用空目录覆盖已有快照。
- `getMaterialIndex` 返回空目录时不能写入/覆盖材料快照；必须保留上一份有内容的真实快照。
- 写作入口同样必须先同步读取 `getMaterialIndex` 缓存/快照；不能等异步 Promise 回来才显示列表。
- 听力套卷列表点击后先用列表项的音频字段进入详情并预备播放器，完整题目、图片和学习包后台补齐。
- 听力套卷列表项的点击 ID 必须兼容 `_id/id`；目录瘦身时也必须保留 `audioUrl/audioCloudPath/audioFileId/audioSource`，避免详情页空壳和播放器 00:00。
- 听力/写作材料入口有目录快照时，不允许先渲染空列表再套用快照。
- 作文详情优先使用上一页写入的 `currentWritingPromptV1`。
- 兜底拉目录时不能阻塞已有作文题显示。

## 验证清单

- 全局检索无 `showLoading` / `hideLoading`。
- 全局检索无等待文案：`加载中`、`准备中`、`同步中`、`生成中`、`处理中`。
- 断网时缓存页面仍能显示旧内容。
- 云端慢时首屏不空白。
- 状态型页面不能只验证缓存首屏速度；必须验证云端刷新后页面收敛到当前 target 的真实数据。
- 含完成数、时长、连续天数的 dashboard，测试步骤必须包含“写入新进度 -> 返回页面 -> 等待 cloud refresh -> 对照数据库”。
- 长时效缓存只允许承担首屏快速展示；与当天完成态相关的刷新不能只放在未等待的后台回调里。
- 生成类按钮可禁用、防重复点击、失败可重试。
- 相关 JS 通过 `node --check`。

## 建议埋点

统一记录：

- `pageReadyMs`：页面进入到首屏核心内容可见。
- `cacheHit`：是否命中缓存。
- `cloudRefreshMs`：后台刷新耗时。
- `dataFresh`：刷新后关键字段是否与当前 target 的云端真实记录一致。
- `firstEmptyStateMs`：空状态出现时间。
- `actionMs`：生成、批改、评分等用户动作耗时。

目标：后续优化先看真实 `pageReadyMs`，不要只凭感觉改。
